# T03 병합 후 사람 재로그온 인수 절차

2026-11-21 캡틴이 현재 로그아웃하기 어려워 실제 재로그온 시험을 병합 후로 이관하도록 승인했다. 지금 재로그인을 요청하거나 도구로 로그아웃하지 않는다. 실제 로그인 자동 기동·콘솔 비표시는 미실측이며 등록·현재 기동 결과나 사용자 승인으로 성공을 대체하지 않는다. 추적 todo는 `.pace/memory/로그온-자동-기동-병합-후-실측.md` 이다.

## 현재 준비 상태

자동 시작 등록과 현재 정상 기동, 정식 CLI 기동/정지/중복/재기동 및 전체 검사 병행·메모리 관측을 마쳤다. 전체 검사 exit 0, 991 pass·0 fail·9 skipped다. 시험 감독은 승인된 최종 정상 기동을 위해 해제됐고, 로그오프를 기다리는 동안 daemon은 등록+기동 상태로 둔다. 작업자가 Windows 로그오프·재시작을 실행하지 않았다.

human-relogon-baseline.json은 T03 검사 종료 후 당시 정상 소유자와 config/시크릿·26개 설치 모듈의 기준점을 보존한다. 이 기준점의 생성은 실제 재로그온 증거가 아니다. T04나 병합 뒤 기동·설정이 바뀌면 이 과거 기준점만으로 새 로그인 기동을 판정하지 않는다. 후속 인수 직전에 최신 승인 운영 상태를 읽어 별도 post-merge-relogon-baseline.json 등으로 새 기준점을 보존하고, 그 이후의 새 boot·기동시각·설정을 비교한다. T03 역사 기준점은 덮어쓰지 않는다.

## main에서 캡틴에게 요청할 시점·내용

실제 병합 후 캡틴이 가능한 시점에, 이 체크리스트와 최신 기준점·기존 원문 증거를 확인한 뒤 요청한다. 병합 전이나 검사/검증 작업 실행 중에는 로그오프를 요구하지 않는다.

1. 캡틴이 편한 시점에 작업 내용을 저장하고 **같은 Windows 사용자로 로그아웃한 뒤 다시 로그인**한다. 단순 화면 잠금/해제와 구분한다. 에이전트는 이 조작을 대신 실행하지 않는다.
2. 로그인 후 PACE daemon을 수동으로 시작하지 않고 약 1분 기다린다. 관련 콘솔 창이 나타났는지 직접 확인한다. 가능하면 승인된 Telegram General의 새 연결 알림 도착 여부도 확인한다. 메시지 본문·그룹·사용자 ID를 보고하거나 복제할 필요는 없다.
3. main에 실제 로그아웃/로그인 완료와 PACE 관련 콘솔 창 표시 여부를 알려 준다. 콘솔 여부는 사람 관측으로 기록하며 VBS 창 스타일만 보고 대신 통과시키지 않는다.

## 재로그온 뒤 읽기 전용 확인

실제 사람 관측이 도착한 뒤에만 준비한 after-relogon 읽기 확인과 같은 범위의 설치 CLI/로컬 조회를 수행한다. 준비한 감사 스크립트는 T03 당시 기준점을 읽도록 되어 있으므로 후속 인수에 재사용하려면 최신 별도 기준점에 연결한 새 읽기 전용 실행으로 기록한다. 과거 T03 기준점을 새 로그인 직전 관측으로 가장하지 않는다. 확인은 start·stop·등록 없이 최대 약 1분 상태 준비를 기다리고 아래를 비교한다.

- 수동 start 없이 status running true·정상 소유자/실제 포트 일치
- 기준점 이후 새 boot·새 기동시각의 인스턴스
- HKCU Run 값·설치본 숨김 런처 정확 일치
- 운영 config·device·시크릿 및 명시 설치 모듈 무변경
- 사람의 콘솔 비표시 확인과, 가능하다면 새 General 연결 알림

임시 실행 파일이 로그오프 과정에서 없어진 경우 실제 감사 사본/해시와 설치본 조회를 사용해 확인한다. 누락된 과거 실행 원문을 사후 재구성하지 않는다. 감사 사본은 원래 import 파일명을 유지하므로 실행 경로를 재준비할 때 이름 연결을 확인한다. 실패하면 자동으로 start를 호출해 자동 기동 증거를 덮지 말고 실제 상태를 main에 보고한다.

후속 todo는 실제 새 관측·사람 진술을 확인한 뒤에만 완료한다. 실제 재로그온이나 콘솔 여부를 확인하지 못하면 후속 인수 항목은 미확인으로 유지한다. T03 병합 전 마감은 사용자 결정으로 수정된 PROJECT P-3·TASK T-4/S-5a의 등록/현재 운영·후속 추적 보존 기준을 독립 판정하며, 후속 실측 성공을 주장하지 않는다.
