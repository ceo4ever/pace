# T04 v4 사전 검토 반복 실패 진단 2 (2026-11-23)

- 원장: R1 fail(2) → R2 fail(1, 자동 재검토) → R3 fail(1, 자동 재검토) → `stage: diagnose`.
- 실패 모음: R1·R2·R3 blocking이 모두 "예상 밖일 때 멈추기" 규칙의 정지 방식 선택이다. R1 running만 강제 중단 → R2 preparing 누락 → R3 승인된 queued·처리 중 승인 콜백 누락. 매번 상태 하나를 덧붙였다.
- 원인 층: **design** — 계속 바뀌는 작업 상태를 판독해 일반 정지/강제 중단을 고르는 설계라, 판독과 정지 사이의 전이가 항상 새 구멍이 된다. 상태 열거로는 닫히지 않는다.
- 조치: 선택을 없앤다 — daemon이 떠 있으면 상태와 무관하게 항상 강제 중단(자손 고정 → SIGKILL → 소멸 확인), 진행 중 작업은 제품의 다음 기동 복구가 처리, 자손을 빠짐없이 확인 못 하면 회수 미확인·격리 유지(R3 should_fix 포함). waiver 문구는 지우고 독립 pass를 착수 조건으로 유지(R3 should_fix).
- 사용자 기준(2026-11-23): 반복 지적은 PM이 근본 조치 후 재검증하고 사후 보고.
