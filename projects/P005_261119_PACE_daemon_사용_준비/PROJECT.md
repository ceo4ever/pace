## 설계

기존 설정 명령과 Telegram 포럼 토픽을 사용한다. General은 운영 명령을 받고, 프로젝트 토픽은 등록된 워크스페이스에 결속한다. 읽기 전용을 기본으로 두고, 쓰기는 허용 사용자가 작업별로 승인한다. 재시작 시험에는 별도 검증 작업을 사용한다. 시험 중 발견한 제품 결함은 재현 요약을 이슈 또는 새 백로그에 기록한다.

운영 반영 전 캡틴 확인 사항은 실행기와 대체 순서, 어댑터 설치 필요 여부, 토픽을 켠 그룹과 봇 및 허용 사용자, 시작 방식, 등록 워크스페이스와 동시 실행 상한이다. 기본 검토안은 읽기 전용과 상한 2다.

인증·권한, 사용자 홈 설정, 메신저 전송은 민감 경로다. 토큰은 대화형 숨김 입력이나 표준 입력으로만 받으며, 증거에는 사용자·채팅 식별자와 토큰 원문을 빼고 관찰 결과만 기록한다. 기존 설정이 있으면 현재 값과 대상 파일을 먼저 확인한다. 쓰기 실측은 승인된 검증용 워크트리의 검증 파일로 한정한다.
