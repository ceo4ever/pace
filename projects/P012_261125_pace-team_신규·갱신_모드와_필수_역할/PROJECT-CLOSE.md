# P012 pace-team 신규·갱신 모드와 필수 역할 — 마감

- 프로젝트: [PROJECT.md](PROJECT.md) · 마감: 2026-11-25

## 목표 달성 판정

달성. 팀 원본의 존재와 출처에 따라 신규 생성·갱신·이전을 선택하고, 세 경우 모두 필수 역할을 합의 원문과 등록 요건으로 점검한다. 갱신에서는 최근 기록의 관측 범위를 구분하고 승인받은 원본만 반영한다. 실제 저장소의 백로그 기획자를 등록해 두 호스트에서 적재했으며, 고정 시점의 근거 대조와 새·기존 백로그의 위임 행동을 관측했다. 허브는 owner 결정의 인계와 독립 검토를 맡는다.

owner가 승인한 중간 범위에서 문제 해결자는 요건 미등록(BL261125_01 담당)으로 표시된다. 해당 역할의 적용 및 두 역할 공동 목표 종결은 후속 프로젝트의 소관이다. 현장 백로그에 대한 위임 효과는 병합·설치 뒤 실사용 증거로 판정한다.

## 보안

`node scripts/secret-scan.ts`를 통과했다. [전체 변경의 독립 보안 검토](evidence/security-review.md)와 T02의 실제 경로·심볼릭 링크·형식 거부 증거를 대조했다. 선택 표지는 경계 검사 안의 일반 파일이어야 하고 영수증은 기존 입력 계약을 적용한다. 프로젝트의 팀 채택을 시작시키는 경로와 실제 호스트 도구 권한은 기존 동작을 유지한다. 팀 역할 적재 확인은 명시 표지를 관측하며 독립 행동·보안 판정은 별도 증거다. 독립 검토는 운영 경로와 시험을 검토하고 대량 평가 산출물에는 전수 비밀 검사를 적용했다. 역할 표지와 비참여 근거는 신고 수준이다. 표지만 있는 역할은 팀 참여자로 추가되지 않으며, 실제 배정 확인은 운영 인수의 범위다.
