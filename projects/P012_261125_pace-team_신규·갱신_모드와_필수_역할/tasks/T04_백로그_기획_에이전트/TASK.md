- 포함: 맡는 일 7개, 금지·입력과 반환·위치/종류·추천 등급과 실행 대조의 등록/적용, 역할 표지, 권고값 선택, 교차 제공자 기능 평가와 음성 대조.

## 접근

T03 갱신 절차로 현재 네 구성원과 최근 프로젝트·백로그 기록을 읽고 허브의 담당 공백을 근거로 기획자를 추가한다. 공통 실행 전 대조, 점검 표지, 허브 HANDOFF를 갖춘 맞춤 maker 정의와 정본을 연결한다. 기획 업무의 길이와 독립 확인 범위에 맞춰 기존 maker 등급인 medium을 권고로 기록하고 현재 저장소 tier 매핑으로 검증한다. 사용자의 결정 권한은 허브에 연결한다. BR 크기는 문서·민감 코드 경로 수, 완료 기준, 새 도구·시험의 비용을 비교하고 한 태스크 단위로 대조한다.
