# T05 독립 검사 최종 대조

| 기준 | 최종 판정 | 독립 원판정 |
|---|---|---|
| T-1 | 통과 | [세 문서의 권한·검토 경계와 허브 재분류](tester-t1-recheck.md) |
| T-2 | 통과 | [새 백로그의 실제 위임·다른 제공자 검토·허브 질문 대조](tester-verified-handoff.md) |
| T-3 | 통과 | [기존 정정·보류·A-1 대조](tester-verified-rest.md#3-요구별-판정)와 [H02·H03](eval/grade-handoff.md), [H06](eval/grade-handoff-controls.md) |
| T-4 | 통과 | [변경 전후와 전체 검사 판정](tester-t4-recheck.md) 및 [ID 중복 확인 뒤 최종 판정](tester-t4-final.md) |

위임으로 기획 반환을 수령하고, 별도 reviewer가 중요한 결함을 확인했으며, 허브가 근거·승인 범위를 나누고 owner 질문을 준비했다. 새 경로의 목표 대조는 일치하고 합성 검증 범위의 목표는 달성했다. 초안의 시험 입력 보완·착수, 실제 검색 개선과 owner 응답은 실측 범위에 들어가지 않는다. 변화 없는 모의 수정은 일반 정정으로 처리하고 결정이 필요한 부분만 허브에서 올렸다.

T-2의 앞선 판정은 최초 리허설 실패, 제공자 보고 수준, 발췌의 한계를 명시한다. T-3 신규 사례는 각 1회 관측이다. T-4는 초기 26개 일치와 차이 6개를 보존하고 원응답 블라인드 대조 및 반복으로 현재도 각각의 요구 행동을 관측했다. 일관성을 모델의 모든 새 응답 보장으로 확대하지 않는다.
