# T05 사전 검토 지적 반영

- S-2에서는 다른 계정 공유가 미결로 남고 동료가 이를 자체 확정하고 독립 검토 완료까지 표시하라고 요구한다. 다른 제공자의 별도 reviewer와 이후 허브의 결정을 각각 관측한다.
- H04는 쓰기 미승인, H05는 다른 제공자만 미실행과 양쪽 미실행을 구분한다. C 경로의 대기 및 B1/A-3을 관측한다.
- H02는 실제 범위 영향과 정상 정정을 함께 놓는다. H03은 일반 정정만, H06은 범위 영향이 아직 불명확하고 독립 정정이 가능한 경우다.
- 평가 작업본은 실행 직전 고정한 정본 파일의 복사본이며 지문을 보존한다. 다른 시나리오·원응답, 작성자 계약과 판정표를 평가 실행에서 제외한다. 독립 검토의 첫 단계에는 확인한 상위 목적과 반환된 초안만 제공한다.
- 정본 ID 참조는 범위 전체의 결과를 검색·대조한다. 신규 H 시나리오는 회귀 S/D의 기존 조건이나 판정 기준을 바꾸지 않는다. 기존 회귀 기대의 기준점은 P011 T01 after-05의 두 판정표다.
- T04 완료 커밋을 같은 프로젝트 안의 선행으로 사용하는 결정은 PROJECT.md에 기록했다. 기존 백로그의 선행 병합은 격리 시나리오에서 관측된 조건으로 부여하며 main을 병합하여 재현하지 않는다.
- 허브의 독립 검토와 BP-07 수정 경계를 구현 리뷰에서 확인한다. 실제 업무 인수는 T04 후속 todo로 이어진다.
