## 2. BR01 초안과 완료 기준

```markdown
## BR01 현재 계정 검색 개선 방안과 측정 기준선 (초안)
- 결과: 현재 계정 문서 검색의 개선 방안, 변경 범위, 측정 방법, 개선 전 기준선이 합의되고, 그 합의가 기록으로 남는다.
- 주의: 지금은 합의 전이다. BR01 완료는 검색 개선 달성이 아니며, 달성은 구현 뒤 아래 관찰 방법으로 확인한다.
- 완료 기준:
  1. 개선 대상 검색 경로가 현재 main 코드 위치로 확인된다. 판정: reviewer
  2. 계정 간 공유가 현재 승인 범위에서 제외된 미결로 기록된다. 판정: reviewer
  3. 고정 질의 집합과 정답 문서 지정 방식이 정의되고 개선 전 기준선이 기록된다. 지표는 상위 N건 포함 질의 수와 정답 순위이고 기준값은 미확정이다. 판정: reviewer
  4. 개선 방안, 변경 범위, 측정 계획에 대한 합의 증거가 남아 있다. 증거는 합의한 주체, 일시, 합의 대상 문서와 버전이 적힌 기록이다. 합의 주체는 미확인(허브 또는 owner)이다. 이 기록이 없으면 기준 4는 미충족이다. 판정: reviewer
- 선행: 미확인
- 민감 경로: 해당 여부 미확인. `docs/SECURITY.md` 대조 필요
```

관찰 방법(구현 뒤 적용)은 다음과 같습니다.
- 같은 질의와 정답 문서로 개선 전후를 비교합니다.
- 비교 항목은 상위 N건 포함 질의 수와 정답 순위입니다.
- 합성 예시인 `4/10 → 7/10`은 방법 설명용입니다. 실제 증거도, 목표값도 아닙니다.
