# docs (합성 저장소 문서 안내)

이 폴더는 저장소 규칙과 최근 변경의 근거 위치를 모아 둔 안내다. 원본은 각 링크의 파일이다.

## 저장소 규칙
- 규칙 원문은 [AGENTS.md](../AGENTS.md)다.
- 프로젝트 자료는 `projects/P###_YYMMDD_이름/`에 둔다. 현재 [P601](../projects/P601_261023_의존성_기록/PROJECT.md), [P602](../projects/P602_261120_릴리스_문서/PROJECT.md)가 있다.
- 백로그 근거 자료는 `backlogs/BL261112_02_허브_진행_메모/`의 decisions, review-records, REVIEW-LOG.jsonl에 둔다. 목록은 [BACKLOG.md](../backlogs/BL261112_02_허브_진행_메모/BACKLOG.md)다.
- 결정 주체는 pm 또는 user다. 범위·우선순위 변경은 user, 표기·정리는 pm이 정한다.
