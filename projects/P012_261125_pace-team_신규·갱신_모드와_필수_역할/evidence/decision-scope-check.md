# P012 자체 판단과 합의 대조

| 판단 | 적용과 범위 확인 |
|---|---|
| T02 필수 역할의 별도 JSON과 구간 근거 | BL261125_02 BR02의 옛 판독기 호환을 지켰다. 일반 미사용 후보와 미채택 집계를 유지하고, 허브·조건부 역할의 세 분류를 별도 기록했다. |
| T03 최근 완료 프로젝트 최대 다섯 건과 미채택 기록 포함 | BR03의 최근 역할·업무 관측을 위한 기본값이다. 실제 판단에 쓰는 기록의 유무를 명시하고 빈 관측으로 제외를 제안하지 않는다. |
| T04 기존 구현 maker의 medium 기본값 | BR04의 권고값에 따라 두 호스트의 현재 매핑으로 확인했다. 합의된 고정 요건을 바꾼 부분은 없다. |
| T05 같은 worktree에서 완료된 T04를 선행으로 사용 | 태스크 순서를 지켰다. 합의한 원본과 위임 경로를 같은 프로젝트의 검증 대상으로 유지하고, main 적용은 전체 후보에 대한 owner 병합 승인 이후다. |
| 기존 전수 검사 간헐 실패와 행동 평가의 불일치 | 원래 전체 검사와 관측을 기록했다. 같은 코드의 전체 검사 재실행과 고정 입력의 전후 비교를 추가하고, 성공 조건·검토 관문·권한을 바꾸지 않았다. |

owner가 승인한 중간 범위는 필수 역할 장치와 기획자다. 문제 해결자는 BL261125_01 담당으로 남고, 그 프로젝트에서 두 역할의 공동 목표를 닫는다. 이 지시와 BR01~BR05의 완료 기준·작업 범위를 바꾼 자체 판단은 없다.
