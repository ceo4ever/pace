## 접근

- `references/project-docs.md`: 역할 경계 표 "길이" 행을 기준 절 링크로, 새 절 "정의서 크기와 분리 기준"(위 기준 내용)을 역할 경계 다음에 둔다. 정의서 템플릿 구성 요소 표 머리글을 `요약 · 상세`로 바꾸고 예시 행에 링크, AGENTS.md 템플릿 더 보기를 읽는 시점 형식으로. 유형별 선택 문서 표에 "모듈·주제 서브 문서(분리 기준 초과 시)" 행을 더한다.
- `SKILL.md`: §3-1에 지도로 쓰고 기준을 넘는 상세는 서브 문서로, §3-4에 분리 서브 문서 등록, §4-1 정의서 행에 측정 항목, §4-4 대규모 조건에 "정의서 기준 초과(분리 필요)", §4-5 예시에 분리 보고 줄. 숫자는 쓰지 않고 절을 가리킨다. SKILL.md 크기 증가는 작게 유지.
- `references/analysis.md`: 새 절 "정의서 측정"(행위로: 바이트 LF 기준, 절 글자 수와 비율, 구성 요소 비고 칸 글자 수, 최상위 코드 폴더 대 구성 요소 표 경로, docs/*.md 대 문서 표). §6 등록 행은 그대로.
- 테스트: `test/project-init-skill.test.ts` 새 파일(기존 `project-dev-skill.test.ts` 형식) — S-1·S-2(변이 포함)·S-3·S-7. `evidence/measure.ts`는 정확 일치로 고치고 `evidence/measure-selftest.ts`로 S-4 사례를 돌린다.
