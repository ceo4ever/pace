# S-8 사례 (임시 — 파일은 고치지 않는다)

## 사례 A — 신규 작성
opi 신규 모드로 Node 저장소(`src/api/`, `src/web/`, `src/worker/`)의 정의서 초안을 막 썼다. 측정 결과: 초안 19,800바이트(LF), `환경` 절 3,400자(배포 절차 문단 2개 포함), 구성 요소 3행 중 `src/worker/` 행 비고가 620자(재시도·큐 경계 설명). 환경 표에는 `| 검사 | \`npm run check\` |`, `| 보안 검사 | \`npx secretlint "**/*"\` |`, `| worktree 준비 | \`npm ci --no-audit --no-fund\` |` 행이 있다.

## 사례 B — 최신화
기존 저장소의 opi 최신화. `docs/README.md`가 41,000바이트, 구성 요소 표 20행 중 9행이 비고 150자 초과, `작업 프로세스` 절 4,100자, `src/dashboard/` 폴더가 구성 요소 표에 없다. 작업 프로세스에 `- 작업자 도구: codex` 줄이 있고 환경 표에 하네스 라벨 4개 행이 있다. 사용자는 아직 아무것도 승인하지 않았다.
