# S02 저장소 요약 읽기

> 생성 파일 — `steps.json`에서 `node <PACE 설치본 app>/skills/pace-playbook-maker/tools/build.mjs --dir <플레이북 폴더>/references/flows/repo-latest`로 만든다(`<PACE 설치본 app>`은 PACE 데이터 폴더의 `app`, 기본 `~/.pace/app`). 직접 고치지 않는다.
위험: 읽기  · 앞: 없음 · 다음: 없음

**목적**: 기본 브랜치·별 개수·최신 커밋을 화면에서 읽는다

**진입 조건**: 공개 저장소 첫 화면이 열려 있다 — 열기: `orca tab create --url https://github.com/<owner/repo> --json`(출력 result.browserPageId가 이후 <page>)

**도구**: `orca` — orca 명령 세 가지면 된다(도움말 불필요): 열기는 enter, 읽기는 command 한 번(다섯 값을 JSON으로 — 값이 null이면 그 요소가 없는 것이니 멈추고 보고), 닫기 `orca tab close --page <page>`. 제목이 화면에서 줄었으면 command의 식이 펼침 단추로 전체 제목을 읽는다

**명령**: `orca eval --page <page> --expression "(async()=>{const q=s=>document.querySelector(s);const vis=e=>e.getBoundingClientRect().height>0;const H='[data-testid=latest-commit-html]';const all=()=>[...document.querySelectorAll(H)].filter(vis).map(e=>e.textContent.trim());let t=all()[0]||null;if(t&&t.endsWith('…')){const b=q('[data-testid=latest-commit-details-toggle]');if(b&&b.getAttribute('aria-expanded')!=='true')b.click();let c=null;for(let i=0;i<20&&!c;i++){c=all().find(x=>x.startsWith('…'));if(!c)await new Promise(r=>setTimeout(r,150));}t=c?t.slice(0,-1)+c.slice(1).split('\n')[0]:null;}const a=q('[data-testid=latest-commit-details] a[href*=commit]');const rt=q('[data-testid=latest-commit-details] relative-time');const st=q('[data-testid=star-button]');return JSON.stringify({path:location.pathname,branch:(q('#ref-picker-repos-header-ref-selector')||{}).innerText||null,stars:st?((st.innerText.match(/\(([^)]+)\)/)||[])[1]||null):null,sha7:a?a.textContent.trim():null,title:t,date:rt?(rt.getAttribute('datetime')||'').slice(0,10):null});})()"`

**화면 식별** (하나라도 다르면 UI 변경)
- 제목: 저장소 첫 화면
- 최신 커밋 줄이 보인다
- 별(Star) 단추가 보인다

**기준 캡처**: `references/flows/repo-latest/shots/S02.jpg` (확인일 2026-11-16 · captured)
