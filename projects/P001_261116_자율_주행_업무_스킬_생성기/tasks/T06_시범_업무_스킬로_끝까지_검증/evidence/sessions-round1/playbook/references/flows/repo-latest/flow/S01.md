# S01 저장소 페이지 열기

> 생성 파일 — `steps.json`에서 `node <PACE 설치본 app>/skills/pace-playbook-maker/tools/build.mjs --dir <흐름 폴더(임시 경로 가림)>`로 만든다(`<PACE 설치본 app>`은 PACE 데이터 폴더의 `app`, 기본 `~/.pace/app`). 직접 고치지 않는다.
위험: 읽기  · 앞: 없음 · 다음: S02

**목적**: 입력한 공개 저장소의 첫 화면을 연다

**진입 조건**: 새 탭이 열려 있다

**도구**: `orca`

**명령**: `orca tab create --url https://github.com/<owner/repo>`

**화면 식별** (하나라도 다르면 UI 변경)
- 제목: 저장소 첫 화면
- 저장소 이름 머리글이 보인다
- Code 탭이 보인다

**기준 캡처**: 캡처 금지 — 열기만 하는 단계라 기준 화면은 다음 단계에서 찍는다
