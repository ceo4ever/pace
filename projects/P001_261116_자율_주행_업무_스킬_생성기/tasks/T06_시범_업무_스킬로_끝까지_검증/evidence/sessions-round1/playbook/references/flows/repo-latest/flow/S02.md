**목적**: 기본 브랜치·별 개수·최신 커밋을 화면에서 읽는다

**진입 조건**: S01 성공

**도구**: `orca`

**화면 식별** (하나라도 다르면 UI 변경)

- 별(Star) 단추가 보인다
