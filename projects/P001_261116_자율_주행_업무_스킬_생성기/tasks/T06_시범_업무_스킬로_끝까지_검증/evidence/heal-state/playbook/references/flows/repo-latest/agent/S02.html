S02 저장소 요약 읽기

목적: 기본 브랜치·별 개수·최신 커밋을 화면에서 읽는다

위험: read · 다음: 없음

진입 조건: 공개 저장소 첫 화면이 열려 있다 — 열기: `orca tab create --url https://github.com/<owner/repo> --json`(출력 result.browserPageId가 이후 <page>)

화면 판정: url ^/[^/]+/[^/]+/?$ · 있어야 함 [data-testid="latest-commit"] · 보이면 안 됨 —

화면 식별: 저장소 첫 화면 · 최신 커밋 줄이 보인다 · 별(Star) 단추가 보인다

도구: orca — orca 명령 세 가지면 된다(도움말 불필요): 열기는 enter, 읽기는 command 한 번(다섯 값을 JSON으로 — 값이 null이면 그 요소가 없는 것이니 멈추고 보고), 닫기 `orca tab close --page <page>`. 제목이 화면에서 줄었으면 command의 식이 펼침 단추로 전체 제목을 읽는다 — orca eval --page <page> --expression "(async()=>{const q=s=>document.querySelector(s);const vis=e=>e.getBoundingClientRect().height>0;const H='[data-testid=latest-commit-html]';const all=()=>[...document.querySelectorAll(H)].filter(vis).map(e=>e.textContent.trim());let t=all()[0]||null;if(t&&t.endsWith('…')){const b=q('[data-testid=latest-commit-details-toggle]');if(b&&b.getAttribute('aria-expanded')!=='true')b.click();let c=null;for(let i=0;i<20&&!c;i++){c=all().find(x=>x.startsWith('…'));if(!c)await new Promise(r=>setTimeout(r,150));}t=c?t.slice(0,-1)+c.slice(1).split('\n')[0]:null;}const a=q('[data-testid=latest-commit-details] a[href*=commit]');const rt=q('[data-testid=latest-commit-details] relative-time');const st=q('[data-testid=star-button]');return JSON.stringify({path:location.pathname,branch:(q('#ref-picker-repos-header-ref-selector')||{}).innerText||null,stars:st?((st.innerText.match(/\(([^)]+)\)/)||[])[1]||null):null,sha7:a?a.textContent.trim():null,title:t,date:rt?(rt.getAttribute('datetime')||'').slice(0,10):null});})()"

요소(번호 = 캡처 박스)

#이름찾기동작대기기대다르면box
1기본 브랜치#ref-picker-repos-header-ref-selector-v0읽기없음브랜치 이름이 보인다멈춘다재캡처 필요
2별 개수[data-testid="star-button"]읽기없음Star 옆에 개수가 보인다(예 124k)멈춘다있음
3최신 커밋 제목[data-testid="latest-commit-html"]읽기없음비어 있지 않다멈춘다있음
4최신 커밋 링크[data-testid="latest-commit-details"] a[href*="/commit/"]읽기없음링크 글자가 7자 해시다멈춘다있음
5최신 커밋 날짜[data-testid="latest-commit-details"] relative-time읽기없음datetime 속성(UTC 시각)이 있다멈춘다있음
