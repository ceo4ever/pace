판정: **pass — 지정된 독립 tester 검증 범위.** 태스크 마감에는 진행 중인 최종 전체 검사 결과를 별도로 연결해야 합니다.

독립 목표 대조: **맞음.** 증명 범위를 먼저 명시하고 구조 검사와 의미 판정을 나누는 전략은 검토 집중이라는 목적에 부합합니다.

목표 달성: **T01 계약 범위에서 달성.** 옛 TASK 호환, 충분 범위의 확장 요구 분류, 부족한 범위·권한 대체·필수 안전 제외 검출을 확인했습니다. 실제 운영의 실패 회차 감소는 이번 관측으로 증명하지 않았습니다.

|---|---|---|
| T-1 | pass | v2 표지를 게이트·verify·스킬이 공유합니다. 절 누락·주석뿐인 절·빈 주체·중복/미지원 표지를 거부하고 옛 TASK·CRLF를 허용합니다. 실제 생성 TASK의 표지와 절 존재·순서 단언도 실행됐습니다. |

- `npm run typecheck`: 통과.
- 지정 단위 테스트 3개 파일: **40건 통과, skip 0**.
- 하네스 이름 필터: **2건 통과, skip 0**.
- 검토 도중 추가된 미정/TBD 문구를 읽은 뒤 `agent-verify.test.ts` 재실행: **11건 통과**.

실행된 검사는 해당 기준을 직접 겨냥합니다. 거부 경로·구형 호환·생성 템플릿·원장 재검토 전이를 단언하며, 기존 해시·증거 변조·사용자 예외 검사는 유지됩니다. 일부 하네스 fixture가 표지를 제거하는 기존 호환 경로지만, 별도의 신규 생성 TASK 경로가 v2 게이트를 검증하므로 검증 대체로 보지 않았습니다.

이전 반례도 재확인했습니다. fenced 코드의 `<!--`, 인라인 코드의 `` `<!--` `` 뒤에 실제 주석을 둔 유효 TASK는 모두 허용됐습니다. 코드 예제에만 있는 절과 중복 절은 거부됐습니다. 템플릿 절 존재를 먼저 단언하므로 이전의 `-1 < 기준 위치` 허위 통과도 해소됐습니다.

구조 누락 뒤 전체 검토 복원은 `agent-review-log.test.ts`에서 확인했습니다. 누락 보완 후 기록은 `rereview_of: null`이고 좁은 재검토 프롬프트가 빠집니다. 이어 발견한 안전 결함의 보완은 R2에 연결되는 정상 재검토로 돌아갑니다. 실패 기록을 지우는 변경은 없습니다. 최신 정본은 미정/TBD 같은 의미적 불충분성에는 단건 억제를 적용하지 않아 목적·안전 평가를 함께 열도록 명시합니다.
