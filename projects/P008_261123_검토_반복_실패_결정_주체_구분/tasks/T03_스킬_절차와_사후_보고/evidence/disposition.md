# 지적·실패 처리

독립 reviewer 첫 판단은 문서 목표 정합에 동의했고 G 전제 불일치·일반 coordinator 질문 기준 축소를 should_fix로 냈다. G를 E′로 고치고 일반 질문 기준을 복원했다. PM 결정 횟수로 새 중단/보고 규칙을 추가하자는 제안은 합의된 매 수정전 영향분류·매 재검증뒤 보고와 별개 자동 횟수 정책이므로 채택하지 않았다. 같은 reviewer는 TASK/BR03 대조 후 이를 note로 낮췄다. 최초 행동 응답과 정본 수정 뒤 여섯 사례 전체 재호출 응답을 모두 보존했다. 최종 reviewer는 최신 응답의 필수/금지 행동을 대조해 pass, 미해결 should_fix0으로 판단했다.

CLI 증명 스크립트 초기 실패4회는 ESM fake 실행, unborn Git HEAD, 임의 프로젝트 폴더의 canonical 불일치, Git 초기 브랜치가 master였던 환경 전제 문제였다. 원문과 부분 출력은 남겼다. 스크립트는 ESM·빈 initial commit·실제 source project new·명시 main 초기화를 사용해 수정했다. 최종 cli-proof-final은 네 경로 모두 통과했다. 이는 합성 입력의 기계 계약 증명이며 실제 provider/사람 승인 증거가 아니다.

행동 증명은 실제 Anthropic이 내놓은 읽기전용 행동 계획이다. 실제 변경·위험한 전송·사람 승인은 수행하지 않았다. OPAL 자동 부트와 호스트 파일명 노출을 각 원문에 남겼으며 완전 격리라고 주장하지 않는다. H는 고정 입력의 합의 자료가 부족하여 합의확인 자체의 검출력에 한계가 있다. 확인으로 영향 모호함을 해소하고 PM으로 분류한 행동은 관측했다. 다음 S7 개선 후보이며 현 계약의 필수 행동 관측과 구별한다.
