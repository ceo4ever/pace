# 상위 목적 (출처: 캡틴 대화 2026-11-18)

PACE의 백로그 대시보드(`backlogs/README.html`)는 서버 없이 file://로 여는 화면이고, 화면 코드(CSS·JS)는 각 PC에 설치된 PACE 설치본에 한 벌만 두고 참조한다.
문제: 진입 HTML이 설치 PC의 절대 경로(file:///C:/Users/<계정>/.pace/...)를 담아, 저장소를 여러 PC가 공유하면 PC마다 이 파일이 Git 변경으로 잡히고, 누가 커밋하면 다른 PC에서는 화면이 깨진다.
목적: 공유 저장소의 대시보드가 어느 PC에서도 Git 변경 없이 동작해야 한다. 캡틴이 고른 방식은 "커밋되는 파일에는 PC 경로를 두지 않고, PC별 경로는 Git 밖 파일로 분리"다.
지켜야 할 것: 기존 사용자 수정 화면·자료는 보존, 하네스(worktree·finish 미커밋 검사)와 자동 갱신 흐름을 깨지 않음, 기존(경로를 담은) 진입점에서 넘어올 길.
