# 사용자 결정 (2026-11-23, 캡틴)

질문: "P007 T02 계획이 진단 뒤 전체 검토에서도 fail이에요. 남은 지적은 실제 누락 2건(사용자 결정과 게이트 연결, PRE-REVIEW 연속성 값), 평가 엄밀성 1건, 세부 1건이에요. 어떻게 할까요?"
선택지: ① 누락 고치고 구현 진행 (추천) ② 다 고치고 검토 한 번 더 ③ S-7 빼고 문서 검사만
캡틴 선택(원문): "누락 고치고 구현 진행 (추천)"
선택지 ①의 내용: 실제 누락 2건과 세부 1건은 계획에 반영하고, S-7은 분류 전 지적과 구체적인 실패 내용을 주도록 고친다. '규칙을 뺀 스킬로도 돌려 탈락 확인'은 하지 않는다. 사전 검토를 더 돌리지 않고 구현하며 구현 후 tester·reviewer가 확인한다. 이 결정은 PRE-REVIEW waiver로 기록한다.
