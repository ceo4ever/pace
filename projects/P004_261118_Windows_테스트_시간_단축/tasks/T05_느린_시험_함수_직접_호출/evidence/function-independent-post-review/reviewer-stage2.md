## 3. nit (마감 판단에 영향 없음)

1. **오류 매핑 중복:** `project-call-process.ts`의 오류 매핑과 `project-call.ts`의 legacy 마커 제거가 각각 `bin/pace.ts`, `runCli`와 중복된다. 원본 위치를 가리키는 주석 정도면 drift를 알아차리기 쉬워진다.
2. **변수 가림:** `BL 생명주기` 블록에서 바깥의 scope 변수 `direct`를 루프 안 `const direct`가 가린다. 동작은 맞다. scope 변수 이름만 바꾸면 기계 변환 규칙과도 충돌하지 않는다.
3. **Telegram save 훅 안의 단언:** 훅 안의 `assert`와 `!`가 실패하면 그 예외가 "디스크" 실패로 흡수되고, 결국 `injected === 1` 불일치로만 드러난다. 거짓 통과는 없지만 원래 메시지를 잃는다. 관측값을 기록해 두고 훅 밖에서 단언하면 진단성이 좋아진다.
4. **`process.argv[1]` 재실행 경로:** 정적 감사 표에 이 경로의 부재를 한 줄 추가하면 S4가 닫힌다.
