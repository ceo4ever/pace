# T04 독립 tester 재검토

**판정 pass. 독립 목표 대조 맞음, 목표 달성 달성.** 동일 검토자가 1·2단계 원문을 보존하고 수정된 결과를 재검토했다.

| 기준 | 판정 | 근거 |
|---|---|---|
| T-1 | pass | 일반 변경의 설치형 선택은 기존 2단계 직접 실행과 최종 원문에 남았다. 이전 재현에서 누락되던 B가 `assume-unchanged` 또는 `skip-worktree`로 숨겨지면 부분 통과 대신 선언된 전체 검사로 전환했고 B의 실제 실패를 종료 1로 전달했다. |
| T-2 | pass | 독립 외부 Git 임시 표본의 `D  src/a.mjs\0?? src/a.mjs\0`은 실제 전체 검사 마커와 종료 0을 냈다. 두 플래그와 실제 sparse checkout도 전체 마커를 냈고 부분 대상은 표시되지 않았다. 네 실행에서 인덱스 바이트가 그대로였다. 설치형 기존 회귀의 staged 삭제·인덱스 플래그·sparse·실행 시간/출력 한도·사전 검사 뒤 대상 소실 5건도 모두 통과했다. 사전 검사 뒤 대상 소실은 종료 3과 실제 사전 검사 마커만 남겼다. |
| T-3 | pass | 수정본 `npm run check` 전체가 종료 0, 995건 중 986통과·9 skip·실패/취소 0이었다. 벽시계 710711.7803ms, 11분 50.7118초다. 원문 명령에 tsc와 Node 시험 실행이 들어 있다. 현재 607개 파일의 SHA-256이 측정 시작과 모두 일치했고 시작·종료 파일 해시 차이도 0개였다. T03 기본4의 5회와 각각 대조한 결과 기존 970건 제거·판정 변화 0, skip 사유 동일, 신규 25건 통과다. 최종 focused 원문은 36/36, skip 0. 최종 빠른 시도 3회의 중앙값은 14.794초, 범위 14.746–15.299초였다. 대표 scout 변경에서 실제 tsc와 2개 시험 파일을 선택했고, 준비 4.686초는 별도다. |

직접 실행한 집중 5건은 로그 두 개에 있다. 첫 실행은 3건 통과, 12.534초, 둘째는 2건 통과, 4.581초였고 두 명령 모두 종료 0, skip 0이었다. 처음 임시 표본의 Windows PowerShell 표준 입력 인코딩 때문에 한글 검사 라벨이 손상되어 최초 시도는 전체 선언 없음으로 종료 3이었다. 코드 포인트로 같은 라벨을 만들어 재시도했고 네 표본이 통과했다. 실패 원문과 성공 원문을 따로 남겼다.

추가로 발견한 차단 결함은 없다. 전체 검사는 독립 검토 세션에서 재실행하지 않았다. 스냅샷은 측정 중 연속 감시를 보증하지 않는다. 실제 설치기·POSIX 셔임과 별도 프로젝트의 폭넓은 속도는 미검증이다. 대표 빠른 검사와 전체 회귀의 범위는 다르며 P-6 최종 검사는 별개다. 작업본은 수정하지 않았다.
