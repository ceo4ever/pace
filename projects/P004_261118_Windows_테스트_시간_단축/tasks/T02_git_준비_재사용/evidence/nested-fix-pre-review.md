## 수정 전 관측

`nested-diagnostic-2026-11-18T12-31-42-214Z/nested.log:972`는 수정 전 실제 19개 `.mjs` 기본 병렬 실행에서 guard 저장 경계 시험의 원래 “임시 폴더가 남았다” 단언 실패를 보여 준다. 새 이름 `pace-playbook-Xia29u` 하나가 관측됐다. 181건 중 통과 180·실패 1·skip 0·종료 1이다. 생성 PID는 이 자연 실행에서 추적하지 않았으며, 이전 T02 전체 단회의 잘린 내부 실패와 동일하다고 확정하지 않는다.

`guard-peer-shared-2026-11-18T12-33-56-695Z/guard.tap` 및 `trace.json`은 guard가 첫 목록을 읽은 뒤 별도 자식 PID가 공용 tmpdir에 정상 접두사 폴더를 만들었을 때 원래 guard가 정확히 그 폴더를 누수로 판정하는 통제 재현이다. guard PID와 생성 PID는 다르며 같은 공용 루트임을 기록했다. 3건 중 1건 실패·종료 1이다.

`guard-peer-isolated-2026-11-18T12-34-20-877Z/`는 실제 소스 수정 없이 기존 `test/helpers.ts`를 Node preload로 적용한 후보 진단이다. 공용 루트의 동료 폴더는 guard 고유 tmpdir 밖에 남으며 3건 모두 통과·종료 0이다. `guard-own-isolated-2026-11-18T12-34-22-631Z/`는 guard 자신의 tmpdir에 같은 접두사 폴더를 남기며 원래 단언이 1건 실패·종료 1이다. 성공 경로만 통과하도록 단언을 약화하지 않았다.

진단들은 소유 루트가 각각 다르며 자연 중첩 실행 후반과 통제 진단이 겹쳤다. 성능 측정이 아니며 이 시간을 T02 단축 효과로 사용하지 않는다. 생성한 실패 증거 폴더는 자체 소유 임시 경로에 보존했다. task의 `diagnose-guard.ts`, `guard-interference.mjs`가 명령·TAP·trace를 기록한다. 진단에 preload를 적용한 실험과 실제 wrapper 수정은 구분한다.
