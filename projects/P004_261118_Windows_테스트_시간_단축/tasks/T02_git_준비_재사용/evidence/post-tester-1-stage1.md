# T02 독립 테스터 1단계

독립 목표 대조는 맞음. 프로세스와 형태별로 실제 Git으로 만든 원본의 독립 복사본을 사용하고 기존 Git·CLI 호출 및 단언을 유지하는 방향은 Windows 전체 회귀의 비용과 검증 범위를 함께 다룹니다.

목표 달성은 미확인. 교차 준비 표본 10회에서 중앙값은 332.905ms에서 24.697ms로 줄었습니다. 최초 캐시 복사는 404.232ms였습니다. 준비 callback의 Git 호출은 60회에서 6회로 줄었고 읽기 전용 HEAD 확인이 한 번 추가됐습니다. 기준 전체 실행 세 건의 results.json과 후보를 이름 및 발생 순번으로 대조했습니다. 기존 963건에서 제거 0건, 기존 skip 9건 동일, 판정 변화 1건, 추가 5건 모두 통과입니다. 후보는 상태 코드 1, 968건 중 958통과·1실패·9스킵입니다. 외부 벽시계 약 35.4초(2.48%) 차이에는 실패한 단회가 포함됩니다. 중첩 playbook-maker 181건 중 1건 실패이며 끝부분만 남은 원본 로그에서 실패한 내부 이름과 인과를 확인할 수 없었습니다. 새 검사는 작업 파일·config·index 상태·ref·object·원본 digest와 별개 HOME, repo 이름을 Git과 파일 변경으로 확인했습니다.

검증·실행 단계에 올립니다. 내부 실패 원문을 확보해 실패 귀속을 확인하고 같은 기준의 성공한 전체 검사와 인벤토리를 확보하기 전에는 목표 달성을 미확인으로 둡니다.

독립성 공개. 동일 제공자의 독립 자식 세션입니다. 사용자 제공 AGENTS 지침과 환경, 호출자의 상위 목표 외에 PACE 부트가 P004/T02 진행 상태와 기존 playbook-guard 병렬 경합 이슈를 노출했습니다. 그 이슈를 이번 실행의 원인으로 채택하지 않았습니다. TASK·PROJECT·BR02·작성자 판단은 읽지 않았습니다. T02 원본 로그는 현재 T02 evidence 쪽 사본을 읽었습니다. 장시간 검사를 시작하거나 worktree를 변경하지 않았습니다.
