## 이전 B-1 해소 여부: **해소**

- **기준선 정의:** T-1과 접근 절이 기준선을 "reporter·preload·추적 환경을 추가하지 않은 `npm run check`의 프로세스 시작부터 종료까지의 벽시계 시간"으로 정의했습니다. P-6 판정에는 이 값만 쓴다고도 명시했습니다. PROJECT 목적이 말하는 "`npm run check` 중앙값 비교"와 일치합니다.
- **상속 경로 차단:** 자식 프로세스로 계측이 상속될 수 있는 환경 변수(NODE_OPTIONS 등)가 기준 환경에 없는지 확인합니다. 있으면 실행 전에 판단을 요청합니다.
- **보조 계측 분리:** 보조 계측은 별도 실행으로 분리했고 중앙값에 섞지 않습니다. reporter는 최상위 argv로만 지정하고, 비상속 fixture가 실패하면 보조 실행을 중단합니다. 지난 검토에서 요구한 합격 조건과 실패 시 동작이 모두 들어갔습니다.
- **결과:** T05·T03에서 계측 비용이 줄어든 만큼이 개선율로 잘못 잡히는 경로가 막혔습니다.
