main 승인에 따라 기존 T01~T05/BR 완료 기록을 되열거나 새 번호를 만들지 않고 P004 마감 전 호환성 통합으로 수행했다. 복구 브랜치 `p004-before-main-integration-20261119`는 통합 전 마감/독립 결과를 보존한 be57784다. main35d0da6을 매 단계 확인하고 소유 worktree에서만 rebase했다. 실제 충돌은 승인된 다섯 경로의 부분집합뿐이었다. main 이동·예상 밖 충돌·새 검사 범위의 임의 추가는 없었다.

## 소스·인벤토리 연결

preflight-source.json은610개 소스를 실제 계수했다. 통합 전609개와 비교한 의미 변경은 README/정의서/초기화 스킬·공유 execute·두 runner 시험 파일의6개이며 새 Vitest driver1개가 있다. 다른7개 새로 추적된 파일은 rebase checkout이 과거의 LF/CRLF 혼합을 정규화했을 뿐 Git blob 내용이 같다. 과거 소유 사본의 실제 원문 SHA와 줄바꿈별0/1 마스크도 연결해 단순한 “전부 LF” 가정을 하지 않았다.
