작업본에 새 명령을 넣어 즉시 실행하는 신뢰 비대칭을 피하려고 checks는 검증한 기준 commit의 map과 작업본 JSON이 같은 때만 허용한다. 로컬 main→master→검증한 현재 HEAD commit을 고정하며 map을 기준 브랜치에 커밋해야 한다. 전체 선언도 그 기준을 우선하지만 실제 부재일 때만 작업본 선언을 읽고, Git 조회 오류는 부재로 바꾸지 않는다. PACE 프로젝트 worktree의 새 map도 main에 반영되기 전에는 전체 전환한다. HEAD 대체 기준은 현재 커밋이며 리뷰된 기준을 뜻하지 않는다. 명령이 읽는 작업본 스크립트/환경까지 격리하는 샌드박스는 아니다.
