# P004 통합 후 독립 최종 결과 1단계

통합 커밋 a5d1115에서 Windows 전체 검사 시간 목표와 기존 시험 범위 보존을 확인했다. 원래 T01 비계측 전체 3회의 중앙값은 1,425.464초다. 통합 후 새 3회는 698.136 / 703.222 / 702.116초이며 중앙값은 702.116초다. 기준의 49.2552%이고 절반까지 10.617초의 여유가 있다. 세 회 모두 절반 이내였다.

로그 원문에서 실제 npm 타입 검사와 전체 시험을 확인했다. 세 회 모두 1,000건·991통과·실패/취소 0·기존 skip 9이며 이름/결과 다중집합은 예상 1,000건, skip 사유는 원래 T01과 일치했다. 로그 세 개, 결과 JSON, 인벤토리 파일의 SHA-256을 다시 계산했다. 소스 610개 작업본 SHA-256 및 HEAD blob ID는 목록과 모두 같았고, 측정 전후 소스 배열도 같았다. 기록상 도구 버전·장비·전원·Defender·비계측 npm 명령은 T01과 같다. 원래 기준의 일부 도구/소스 바이트 정보와 연속적인 호스트 부하는 확인할 수 없다.

a5d1115의 Vitest 드라이버와 전용 시험 파일은 main과 같은 blob이다. changed의 실제 전체 전환은 통합 전과 같은 계획 guard를 사용하며, 실행 소스가 같아 이전 집중 설치형 CLI 관측이 적용된다. 별도 Git 저장소의 Node·Python과 Vitest 관련 변경 전환을 입증하나 이 PC의 실제 기본 PACE 설치본 교체를 관측한 것은 아니다.

이 단계는 기존 프로젝트 계약, 통합 검토와 보안 결론을 이미 아는 동일 검토자의 연속 검토다. 결과를 먼저 판단하는 동안 새 작성자 final-results와 PROJECT-CLOSE를 열지 않았다. 새 실행이나 저장소 변경 없이 2단계에 판단을 전달했다.
