초기 launcher는 실제 측정 호출 전에 상위 폴더명 조건에서 종료했다. 원본 도구 두 개의 보존 SHA를 맞췄고, T01 검증 코드가 시험보다 먼저 출력 폴더명을 검사하는 점을 확인했다. 실제 전체 검사는 0회라 제외가 맞다. 폴더·라벨·검증기 입력을 정정하고 새 버전의 도구 9개를 실행 전에 고정했다. 현재 9개 SHA와 시작 전 기록이 일치한다. 초기 오류 전체 stderr 파일과 호스트 연속 부하는 확인되지 않았다. 수정된 로직은 허용된 해당 라벨과 증거 경로를 사용하고 기존 원문·시간 비교식·실행 소스를 유지했다.

보안은 두 누적 층으로 확인했다. 이전 39,968,553바이트 전체 패치의 독립 검토와 a5d1115 통합 패치/집중 원문 결속 검토를 재사용했다. 이번 작업본에서 추가된 마감·증거 증가분은 수정 5개·새 파일 41개, 1,766,939바이트였다. 경로·현재 파일 내용 SHA-256 목록의 결속값은 e10f7a3ef85fb978048f7969a61d900cf7c4043260d100b5191245d6dcdf9e4c다. 제품, 테스트, 배포, 의존성 실행 소스 신규 차이는 없었다. 텍스트 전체 패턴 대조에서 자격증명 후보와 이메일 형태는 0건, 일반 로컬 Windows 경로 메타데이터 포함은 9개였다. 이전 두 should_fix는 사용자 문서에 반영됐다. 기존 기계 보안 검사 통과는 문서 기록이며 새 검사는 재실행하지 않았다.

- **handoff** — 다른 PC/OS와 POSIX 설치 실기, 실제 외부 Vitest 엔진 전 범위, Windows 임의 자손 회수는 이번 Windows 측정과 모의 로컬 실행기 검증의 범위 밖이다. 외부에 증거를 제공할 때 로컬 경로 메타데이터가 있는 원문과 공개 자료의 구분을 유지한다.

마감 문서의 대기 문구는 이 판정으로 해소할 수 있다. 별도 finish 검사 통과, 승인 후 병합과 실제 설치 반영은 이 검토로 판정하지 않았다. 이번 검토는 작업본을 수정하거나 시험을 다시 실행하지 않았다.
