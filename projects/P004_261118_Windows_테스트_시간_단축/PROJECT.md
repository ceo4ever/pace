## 설계

- T01에서 같은 PC·도구 버전·기준 커밋·명령·임시 폴더 격리 방식으로 실행을 순서대로 3회 반복한다. 전체 벽시계 시간과 Node 파일·시험 시간, 실패·건너뜀과 종료 코드를 기록한다. 기존 공용 임시 폴더 경합이 섞이지 않도록 실행별 전용 임시 폴더를 사용하고 비교 측정에도 같은 방식을 적용한다. 실패가 남으면 원인을 기록하고 BR01의 실패 0건 계약에 따라 판단을 올린다.
- T02와 T03은 BR01 기준선 뒤 순서대로 수행한다. 단계마다 비교 대상 커밋과 시간을 남겨 효과를 확인하고 T04는 두 단계가 끝난 뒤 진행한다. T05는 당시 누적 실측으로 전환 대상과 종료 지점을 정한다.
- T04는 기존 `pace test` 선택기와 매핑을 검토해 재사용 가능한 부분을 쓰고, 매핑이나 추적에서 설명할 수 없는 변경은 전체 검사로 전달한다. `finish`는 정의서의 전체 검사 명령을 사용한다.
- 보안 영향: 측정 출력에는 재현에 필요한 도구 버전·시간·시험 식별자를 남긴다. 임시 저장소는 시험이 소유한 경로에서 만들고 사용자 Git 설정이나 실제 저장소를 변경하지 않는다. 선택기·실행 경계를 수정할 경우 경로 및 인자 검증과 선택 실패 시 동작을 리뷰한다. 설치 스크립트와 프로젝트 하네스는 작업 범위 밖이다.
