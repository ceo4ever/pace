# T08 독립 행동 검증

19개 사례가 있다. S1~S6, S7 A·B·C·C′·D·E·E′·F·G·H·J, S8, S9를 차수마다 각각 새 읽기 전용 세션으로 실행했다. S6에는 별도 빈 작업 폴더와 스킬 이름·설명만 줬다. 나머지는 해당 차수의 프로젝트 스킬과 참조 문서를 복사했다. 실제 TASK·PROJECT·eval 기대표와 이전 응답은 작업 폴더에서 제외했다. 프롬프트는 상황만 포함하며 다음 파일 이름에 대응한다.

작업본 P013을 검토할 때 합의한 이전 리뷰 실행본으로 `pace agent run --agent claude --mode p`를 호출했다. 각 실행의 PACE_HOME은 임시 빈 디렉터리였으며 PACE 자식 부트를 억제했다. provider는 각 응답의 실제 도구 메타데이터다. 실행 도구 목록과 접근 흔적, 외부로 내보내지 않은 원시 스트림의 SHA-256 및 세션 ID와 임시 경로를 정리한 실제 답변을 보존한다. 노출 재료의 전체 바이트·줄 수는 `readable-files.json`, 실제 Read/Grep/Glob 입력은 각 답에 있다. 전체 파일 바이트를 모델의 자기보고로 계산하지 않았다.

| 차수 | 변경 사유와 관측 |
|---|---|
| 1 | 최초 축소안. S7-C에서 기록 뒤 설계 수정, S7-C′에서 잘못된 decision 입력 제안, S8에서 앞 단계 누락이 있었다. |

고정 기대표 SHA-256은 `732ca26923be8c881db6c78df8d222a5d169f4a7505aae8a63a6a84a05377a6c`이다. 네 차수의 각 입력을 바이트 단위로 대조했다. 이후 정본 시나리오 표의 빈 줄만 지웠고 입력·판정 행은 같았다. 정본의 구현 경로와 무효 명령 안내는 최종 문구 검사에서 대조했다.
