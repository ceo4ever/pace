## 재료

- BR08, 기존 `reviewer.md`와 `decision-rights.md`의 독립 검토·A-1·A-3·B1 절차, 실제 도구와 P011 문구 고정 시험.
- 직전 커밋의 추적 TASK 분포, 기존 S1~S7과 독립 세션 행동 eval.
- 외부 시스템 계획의 반복 실패 선례와 검색 근거.

## 증명 범위

- 판정 주체: 실제 check 출력·Git 전후 텍스트의 자동 대조와 격리된 독립 세션의 행동 응답.
- 포함: TASK 크기·다른 태스크 기준 경고, 외부 시스템 선례 확인 안내, 핵심 검토 문서의 분량과 소스 대조, 기존과 새 행동 시나리오.
- 범위 밖: 검토의 계산·예산·승인 권한 또는 필수 게이트 기준 변경. 경고는 진행 판정을 바꾸지 않는다.

## 접근

기존 check 출력에 경고만 연결한다. 80줄은 추적 TASK 전체 P90과 완료 TASK P80(각 78줄)에 가까운 값이다. check/done에 들어온 승인 후보의 본문을 사용한다. 마감 전 check의 기존 실패를 유지하며 읽을 수 있는 TASK에는 경고를 붙인다. docs/SECURITY.md의 check/done 경계는 실패 반례를 포함해 검토한다. 구조 변경 대신 원문·권한·예외 판단의 정본을 연결하고 도구가 낸 상태와 세부 실행법은 명령·소스로 찾게 한다.
