## 목적

검토 대상이나 제공자를 바꿔도 태스크·백로그 검토가 정해진 예산에서 멈추게 한다. 두 번째 판정은 앞선 blocking 해소와 수정이 만든 결함에 집중한다. [프로젝트 P-1·P-2·P-5](../../PROJECT.md#기준)

## 증명 범위

- 판정 주체: 임시 폴더의 실제 verify 명령 처리와 주입 실행기 호출 수를 자동 테스트로 판정한다. 검토자는 독립적으로 계약·증거와 테스트 검출력을 확인한다.
- 포함: 단계별 합산, 지속 기록·동시 진입, 전체·범위 재검토 입력, 소진 시 무호출, 중단·무효·옛 원장 처리, 측정 출처.
- 범위 밖: 소진 뒤 공동 시도·owner 결정은 BR02, 판정 질문과 지적·증거 구조는 BR03·BR04, verify 밖 명령의 혼합 실측은 BR06, 측정 집계는 BR07이 맡는다.

## 기준

| # | 완료 기준 |
|---|---|
| T-1 | 태스크는 루트·`evidence/` 원장을 합쳐 사전과 구현 후를 분리하고, 백로그는 폴더당 한 단계로 센다. 각 단계의 두 판정은 대상 수정·경로·제공자·pass·decision 변경 뒤에도 누적된다. |
| T-2 | 한 단계에서 전체 검토 1회와 범위 재검토 1회를 허용한다. 두 회를 썼거나 판정 없는 시도까지 포함해 호출 4회를 썼으면 종료 16과 범위·단계·양쪽 집계를 내며 실행기를 부르지 않는다. |
| T-3 | 중단·무효·unknown은 판정 예산에서 빠지고 호출에는 남는다. 공통 예약 지점에서 BR06 호출도 같은 잠금과 집계를 쓴다. 옛 pass/fail도 소급해 세고 옛 원장 읽기와 비예산 대상의 정상 검토는 유지된다. |
| T-4 | 실행 결과의 `duration_ms`·`usage`를 원장에 기록한다. 토큰 미보고는 null이며 예산에 영향을 주지 않는다. 관련 문서와 전체 회귀 검사를 유지한다. |

## 접근

- 실제 대상 경로에서 범위를 찾는다. 태스크 디렉터리부터 공유 잠금을 사용하고 검토 호출을 실행 전에 원장에 예약한다. 불완전 결과와 기존 행을 구분해 회차를 세고, 원장에 같은 호출을 두 번 합산하지 않는다. 일반 대상은 기존 대상 기준 원장을 유지한다.
- 두 번째 판정의 기준점은 단계의 직전 유효 판정이다. 대상이 바뀌어도 원문과 스냅숏 비교로 범위 재검토한다. 유효하지 않은 첫 시도는 판정 자리를 쓰지 않는다.
- 4회는 전체·범위 검토 두 번과 중단·무효 등 판정이 없는 시도 두 번을 감당하는 고정값이다. 기존 행은 확인 가능한 검토 시도만 소급해 센다. 값의 원본은 검토 원장, 미보고 값은 null(표시 `미확인`)로 두며 후속 BR03에 연결한다.
- `src/agent/review-log.ts`·`verify-cli.ts`, 검토 원장 시험, 관련 문서를 수정한다. 먼저 실패하는 임시 폴더 시험으로 확인한다.
