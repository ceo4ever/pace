# T06 verify 밖 검토 고정과 사전 검토 기록 생성

- 프로젝트: [P013](../../PROJECT.md) · 백로그: [BL261124_04_검토_예산과_재현_근거_지적](../../../../backlogs/BL261124_04_검토_예산과_재현_근거_지적/BACKLOG.md)
- 상태: 완료
- 사전 검토: v1
- TASK 형식: v2

## 목적

verify 밖의 독립 검토도 요청 순간의 원문과 같은 예산으로 추적한다. 사전 검토 기록을 원장에서 생성해 수작업 전사와 현재 대상의 혼동을 없앤다.

## 재료

- BR06의 호출 예약, 원문 고정, 판정 수집과 PRE 생성 기준.
- T01~T04의 두 원장 합산, 검토 상태·기준 ID와 형식 표지. T05의 `review.permission`, 현재 TASK 게이트와 사용자 예외.
- 일반 외부 넘김과 기존 의무 복구의 경계. [검토 설계](evidence/pre-review-design.md)

## 증명 범위

- 판정 주체: 동일 CLI·원장·스냅숏을 대조하는 시험과 독립 검토. 검토자·제공자 출처는 호출자가 실제 기록을 확인한다.
- 포함: Git·본문 지문을 낸 시점, 외부 판정의 한 번 등록, verify와 같은 호출 및 판정 예산, 실패와 옛 원장 입력, PRE의 안전한 생성·갱신.
- 범위 밖: 외부 검토를 자동 실행하거나 독립 세션을 인증하는 작업, 검토 수치 집계, 스킬 정본 축소.

## 기준

| # | 완료 기준 |
|---|---|
| T-1 | `review-hand`는 공용 잠금·예산 아래 검토 단위의 `review-records/`에 대상·정규화 해시·원문을 고정한다. 디렉터리·파일 링크와 경로 이탈을 거부한다. 미완료 고정도 호출 1회다. 소진·공동/사용자 승인으로 열린 복구·상위 조치는 verify와 같은 상태로 읽고 새 고정 없이 종료 16 및 `ran: false`와 BR02·T09 후속 경로를 반환한다. 별도로 허가된 복구는 기존 verify의 조치 근거와 함께 실행한다. |
| T-2 | `review-record`는 고정·대상·단계·지문과 원문을 대조한다. verify와 동일한 구조화 지적·필수 기준 증거 상태·T05 허가 검사에서 판정을 다시 계산한다. 제출한 말미 판정과 다르면 계산값을 원장에 남긴다. 예약은 호출 1회로 유지되고 유효 pass·fail은 판정 1회가 더해진다. unknown은 판정 회차에서 제외한다. 고정 없음·변조·재사용·잘못된 단계·판정 상한을 거부한다. |
| T-3 | 고정 뒤 대상 내용이 바뀌어도 최초 원문은 복구된다. 변경 중인 TASK로 기록된 회차에서는 현재 계약을 허가하는 pass를 만들 수 없다. 상태와 CRLF 정규화는 기존 게이트와 동일하다. |
| T-4 | `review-pre`는 독립·연속성, 실패·같은 제공자 대체 사유, T05 허가를 원장에서 옮겨 기존 PRE 게이트와 같은 판정을 낸다. 중단·무효·미확인과 다른 단계는 제외한다. 기존 사용자 예외는 `by: user`, 현재 TASK 해시, 승인 근거와 최신 실패가 맞을 때 그 기록을 보존한다. 새 승인을 만들지 않고 태스크 폴더 안의 일반 파일만 갱신한다. |
| T-5 | verify·외부 고정을 섞은 실제 CLI 시험, PRE 생성과 반례, 기존 `pre-review`·`project-dev-skill` 회귀, `npm run check`·독립 검증과 `docs/AGENT-CALL.md`의 명령 설명을 갖춘다. |

## 접근

외부 검토 고정과 직접 호출에서 기존 단위 잠금·공용 호출 예약·구조화 판정기를 함께 사용한다. 원본은 검토 단위 내 기록 폴더에 저장하고 예약 지문과 대조한다. 외부 검토자·제공자는 제출 출처로 기록한다. PRE는 원장의 참조·원문으로 생성한다.
