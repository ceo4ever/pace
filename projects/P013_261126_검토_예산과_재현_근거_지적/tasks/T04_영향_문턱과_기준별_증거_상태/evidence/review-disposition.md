# T04 검토 반영

- 사전 계약에서 불충분한 안전 경로의 미확인 결과, 기준 ID 대조, 승인 뒤 증거 상태 보존, 원장·고아 기록의 형식 누락 반례를 명시했다. [사전 검토](../PRE-REVIEW.json) [계약 대조](pre-review-stage2.json)
- 처음에는 형식을 읽지 못한 첫 응답도 범위 재검토의 기준점이 됐다. 지적을 판독했고 증거만 보완하는 경우에 한해 범위를 유지한다. 안전이나 형식 전체가 미확인이면 다음에 전체 판정을 한다. 단계별 관측과 합쳐진 완료 기준 절도 지원한다. [첫 검토](review-records/R1.json)
- 다음 검토는 새 계약을 열어도 기존 미확인 응답으로 범위를 줄이는 경로를 확인했다. 기준점 후보를 일반 예산의 현재 원장 구간과 확정 기준 ID에 묶는다. 새 계약 직후 전체 판정의 반례를 별도로 시험했다. [두 번째 검토](review-records/R2.json)
- 초기 전체 실행의 부트 지연 한 건은 단독 실행에서 통과했다. [단독 재실행](full-check-boot-retry.log)
