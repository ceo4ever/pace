## 목적

재현 가능한 지적의 영향이 합의한 목적·기준·필수 안전에 닿을 때 검토 관문을 막는다. 기준의 증거가 부족하면 보완 관측을 요구한다. 실제로 증거 공백을 수용하고 진행하려는 선택은 A-3 요청으로 연결한다.

## 재료

- BR04의 영향 문턱, 필수 안전의 재현 예외, 기준별 증거 상태.
- T03의 구조화 원문과 기계 판정 및 복구, T09의 한정 확인과 실제 A-3 요청, 결정 권한 A와 B1.
- 태스크·백로그의 수용 기준과 독립 reviewer·tester의 관측 기록.

## 증명 범위

- 판정 주체: 명령의 기계 판정과 독립 reviewer·tester. 실제 제공자의 입력·출력은 동작 증거로 남긴다. 보안과 데이터 위험의 실제 존재 및 사람 결정 원문은 독립 관측·허브가 확인한다.
- 포함: 영향 분류·재현 근거 예외, 수용 기준과 상태·관측 근거, 상태 누락·과거 원장·재검토·고아 기록의 처리, A-3 연결과 기본 보완 경로, 검토 문서 및 시험.
- 범위 밖: 허가 범위의 수정은 T05, 제어 밖 검토 입력은 T06, 실행 권한 확장은 BL261124_02에서 다룬다.

## 기준

| # | 완료 기준 |
|---|---|
| T-1 | 유효한 재현 근거가 있어도 합의 목적·기준·필수 안전의 영향이 없으면 should_fix다. 비안전 영향은 유효한 위치·실패 조건·재현 수단을 갖춰야 관문을 막는다. 기준 영향을 주장하면 확정 기준 ID와 대조한다. 원래 등급, 근거, 영향과 기계 등급을 보존한다. |
| T-2 | 보안·데이터 손실·비가역 위험은 위험한 입력을 실행하지 않고도 입력·도달 경로·결과가 있는 설명으로 판단할 수 있다. 위치와 정상 재현 근거 또는 안전 경로의 입력·도달 위치·결과가 불충분하면 안전 근거 미확인으로 보류하고 보완 관측을 안내한다. 영향 이름만으로 유효 blocking을 인정하지 않는다. |
| T-3 | 태스크 사전·사후와 백로그의 확정 자료에서 읽은 필수 수용 기준과 응답을 독립으로 대조한다. 자료를 판독할 수 없으면 미확인이다. 있음·없음·미확인을 기록하고 빠진 상태나 증명할 근거가 없는 있음을 미확인으로 처리한다. 없거나 미확인인 필수 증거 하나가 있어도 기계 판정은 통과하지 않는다. |
| T-4 | 증거 공백만으로 owner 결정 요청을 열지 않는다. 도구가 보완 관측을 안내하고, 공백을 안고 진행하는 실제 제안은 기존 A-3 절차에 연결한다. 결정 원문과 증거 상태는 각각 보존한다. 재검토 프롬프트는 직전 증거 상태, 바뀐 증거와 그 영향만 다시 판단하도록 고정한다. 과거 원장·T09 한정 확인과 새 기록의 복구 및 재검토 판정이 일치한다. |
| T-5 | 가짜 실행기의 경계 반례, 실제 명령 처리와 다른 제공자 응답 형식, 독립 검토·시험 및 선언 전체 검사를 통과한다. |

## 접근

- 새 검토의 반환 스키마에 영향과 기준별 증거 상태를 추가한다. 요구 기준은 응답이 정하는 대신 검토 대상의 확정 자료에서 읽고 프롬프트와 판정 입력에 보존한다.
- 새 평가에 필요한 입력과 판정을 원장·기록에 연결한다. 새 문맥과 형식 버전을 원장과 기록에 보존한다. 과거의 명시된 형식으로 이전 원문을 읽고, 새 기록은 근거 필드를 지워도 구버전 판정으로 복구할 수 없다. 질문과 연관된 영향과 실제 재현 예외를 분리한다.
- 영향 조치는 승인 이전에 결정 권한 A에 대조한다. 도구의 증거 관문과 승인 요청 생성 관문은 별개의 관측으로 검증한다.
