# T02 독립 검토 지적 처리

owner가 필요한 독립 확인과 A-3 승인 사유를 구분했다. 승인 경계와 일반 검토 종료가 동일 요청으로 합쳐지지 않도록 계약·스킬·CLI·시험을 맞췄다. [재검증 결정 원문](owner-decision.md) [상한 결정 원문](owner-confirmation-limit.md) [독립 D16](eval-D16.json)

| 지적 | 처리 |
|---|---|
| 소진 뒤 모든 조치가 A-3으로 이어짐 | 소진은 허브 판정 자료를 낸다. 명시적인 `skip`·`weaken` 제안만 A-3 자료로 기록한다. 허브가 필요한 확인을 선택했을 때 합의 상한을 넘기면 지적·대상·해시·사용 횟수와 함께 A-1 자료를 기록한다. |
| 확인을 못 받거나 여전히 fail이면 다음 독립 확인이 막힘 | 같은 ID·원래 위치당 1회, 태스크 두 단계 합산 또는 백로그 폴더당 최대 2회다. 같은 확인의 B1 복구는 기존 1회로 센다. 최신 변경도 상한을 공유한다. 초과 확인은 A-1 요청과 일치하는 대상·해시에서 명시적 owner 승인으로 한정 확인을 연다. |
| reviewer pass와 tester fail의 근거 연결이 느슨함 | 직전 원장 기록과 대상 지문, 독립 지적 원문의 경로·내용 SHA-256, 원문에 적힌 지문과 실제 fail, 재현 조건을 함께 대조한다. 직전 검토 기록을 원문으로 쓰면 본문 해시·대상 해시를 원장과 대조한다. 별도 tester 원문의 실제 출처는 입력자가 확인한다. 시험은 옛 지문과 원장 기록 위조를 거부한다. |
| 확인 중 대상 변경 | 실행 준비에서 공유 잠금 아래 대상 해시를 고정한다. 확인이 끝날 때 다른 해시면 독립 원문을 보존하고 최신 판정을 미확인으로 남긴다. |
| 일반 공동 재검증 pass 뒤 새 결정 | 같은 단계에서 공동 재검증 pass 뒤에는 새 일반 공동 재검증을 등록·실행할 수 없다. 후속 증거 확인은 제한된 별도 경로를 사용한다. |
| 요청 투입 뒤 다른 해시가 단위를 계속 차단 | 현재 대상 해시와 기존 승인 요청이 다르면 승인 기록을 거부한다. 허브는 같은 대상의 요청을 명시적으로 철회한 후 최신 대상에 대해 실제 조치를 다시 판정할 수 있다. |
| A-3 지적과 선택지 형식 | 담당자가 대상의 최신 지적과 해당 A 판정·이유, 선택지와 추천을 입력한다. 보고서는 입력을 보존하고 대조 가능한 최신 지적이 빠지면 제출이 거부된다. |
| 추가 blocking을 미확인으로 바꿔 B1으로 재실행 | 추가 blocking을 포함한 fail은 원문과 함께 보존한다. 충돌하는 pass와 실행 중 대상 변경은 미확인으로 표시하고, 원문에 pass·fail이 있으면 B1 복구를 열지 않는다. |
| 소진 보고의 진단 누락과 시간 초과 보고 누락 | 단계 원장의 진단과 근거 경로를 소진 출력·파일에 추가했다. 시작한 수정 확인이 시간 초과되면 미확인 사후 보고를 남기며, 판정을 받지 못한 같은 확인은 B1으로 복구할 수 있다. |
| 마지막 독립 수정 확인의 신규 반례 | 이미 통과한 단계에는 공동 재검증을 열지 않는다. 무효 기록과 원문을 짝지어 소진 보고에 쓰고 그 지적은 판단 후보에서 제외한다. A-3 답은 요청 선택지와 대조한다. 보조 출력 쓰기 전에 확인 보고를 남기며, B1에서 교차 제공자가 계속 시간 초과되면 같은 제공자로 복구한다. |
| 실제 마감 판정 | 수정 확인 보고서와 실제 독립 판정을 원장에 연결한다. 필수 증거와 현재 승인 범위의 기계적 마감 대조는 P013 T05의 계약이 맡는다. |

일반 검토에서 유효한 판정을 한 번도 얻지 못한 경우 소진 보고는 허브의 장애 복구 대상으로 남긴다. 직전 지적의 수정 여부를 확인하는 명령은 유효한 기준점이 있을 때 사용한다. 복구를 계속하거나 실제 생략·완화 제안을 승인 대상으로 올리는 결정은 권한 정본에 따른다.

사용자 정정 이후 구조 수정은 [진단](structure-diagnosis.json)과 [정정 원문](owner-decision.md#필요한-구조-수정과-재검증의-결정-주체-정정)에 따른다. 선행 검토의 A-1 확인 승인은 그때의 원장과 원문으로 보존한다.
