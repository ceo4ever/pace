## 목적

단계별 일반 예산이 끝난 뒤 허브 공동 시도와 실제 A-3 요청을 처리할 수 있게 한다. 검토 자체는 필요한 만큼의 근거를 보존하고, 합의 밖 결정을 owner에게 올린다. 수정 확인과 `upper_review`는 T03 이후 T02b가 구현한다.

## 증명 범위

- 판정 주체: 태스크·백로그의 실제 명령 처리, 단위별 실행기 호출 수와 원장·보고 대조, 독립 reviewer·tester. 승인 입력자는 owner 원문을 대조한다.
- 포함: 아래 판정표, 소진 보고, 실제 A-3 요청, 같은 대상·해시의 승인 회차, B1 시도 속성과 일반 산출물 호환.
- 범위 밖: 수정 확인과 문턱 뒤 상위 검토는 T02b, 구조화된 지적은 T03이다. 판정표와 기준 밖 조합의 제안은 note로 남긴다.

## 기준

| # | 완료 기준 |
|---|---|
| T-1 | 일반 예산은 단계별 판정 2회·호출 4회다. 미통과 단계의 공동 시도는 허브 결정·대상·해시가 맞을 때만 열린다. 태스크 두 단계 합산 또는 백로그 폴더당 공동 시도는 최대 2회이고, 어느 검토 유형이든 단계의 마지막 유효 판정이 통과면 공동 검토를 열지 않는다. |
| T-2 | 소진 시 대상·유효 판정 추이·진단·적용 조치·무효 근거를 보고한다. 유효 판정 0에서 일반 호출을 소진하면 허브가 근거를 남겨 첫 전체 판정을 공동 시도 안에서 복구할 수 있다. 같은 기록은 1회 사용한다. |
| T-3 | 필수 검증 생략·완화나 증거 공백·잔여 blocking을 안고 진행하는 선택은 근거·선택지·추천과 함께 A-3 요청을 만든다. 대기 중 같은 단위의 검토 모두가 멈춘다. PM은 검토나 blocking을 대신 승인하지 않는다. 일치하는 owner 답이 정한 대상·해시와 회차만 연다. |
| T-4 | B1은 별도 허가 유형 없이 같은 시도의 `cross: false`와 교차 미실행 사유로 보존한다. 응답·기록·원장·후속 보고를 대조한다. 관리 단위 밖 일반 원장 동작과 문구 고정 시험을 유지하고 전체 검사를 통과한다. |

## 다음 검토 판정표

| 현재 상태 또는 실제 조치 | 실행 또는 보고 |
|---|---|
| 일반 예산이 남고 열린 결정 요청이 없음 | 일반 검토 |
| 예산 소진·미통과·공동 시도 2회 미만·일치하는 허브 기록 | 지정 공동 검토 |
| 공동 시도 소진 | 차단과 소진 보고. 수정 확인은 T02b |
| 호출 상한·유효 판정 없음·일치하는 허브 기록 | 첫 전체 검토 복구. 공동 시도 1회로 집계 |
| 검증 생략·완화 제안 또는 owner 답 대기 | A-3 요청 자료. 대기 중 단위 검토 차단 |
| 일치하는 owner 승인 회차가 남음 | 지정 회차만 실행 |
| 마지막 유효 판정 통과 또는 일치하는 후속 기록 없음 | 공동 호출 차단 |

## 접근

- 공유 잠금에서 원장 스냅숏을 한 번 읽어 단계·최신 유효 판정·남은 승인 회차를 계산한다. 기록과 실행은 같은 공동 시도 조건을 사용한다.
- A-3에는 실제 생략·완화안을 기록한다. 승인 입력자는 원문을 대조한다. 호출 상한과 허브 조치 내역은 owner 요청과 구별해 보고한다.
