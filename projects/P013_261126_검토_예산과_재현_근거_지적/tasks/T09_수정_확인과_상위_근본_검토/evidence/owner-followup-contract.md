# T09 owner 후속 계약

[owner 원문](owner-endpoint.md)에 따른 두 변경의 증명 범위다. 완료한 T09의 사전 계약과 구현 이력을 그대로 연결한다. [기존 계약](../TASK.md)

| 기준 | 완료 조건과 관측 |
|---|---|
| R-1 | 태스크·백로그의 원장 구조 진단과 수정 확인 진단은 최신 같은 대상의 유효 실패, 근거 파일과 지문에 연결한다. 연속 실패가 있어도 근거를 생략할 수 있는지 입력 반례로 확인한다. |
| R-2 | 근거가 유효한 진단 뒤 같은 단위의 독립 재실패는 남은 일반·공동·수정 확인 회차와 관계없이 즉시 `upper_review`로 보류한다. 다른 대상의 pass는 진단을 닫지 않는다. 원래 진단 대상의 유효 pass와 미확인 응답을 별도로 시험한다. |
| R-3 | 상위 후속 확인 두 회도 실패하면 대상·단위, 일반·공동·수정 확인·상위 두 번의 결과, 각 근본 원인과 적용한 해결안, 마지막 실패의 재현을 동일 보고에 담는다. |
| R-4 | A-1 보고 선택지는 기준 조정, 보류, 한 번 더다. 허브 추천과 이유 또는 기본 추천과 출처를 구별한다. owner 회신 이후의 실행 범위는 그때 확정한다. |
