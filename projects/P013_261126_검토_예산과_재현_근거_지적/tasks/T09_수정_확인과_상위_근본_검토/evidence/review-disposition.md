# T09 검토 반영

- 사전 검토에서 해결안 적용의 A-1·A-3 반례와 수정 영향·독립 근거를 계약에 추가했다. 역할과 제출된 근거의 실제 진위는 허브가 대조한다. [사전 검토](../PRE-REVIEW.json) [계약 대조](pre-review-stage2.json)
- 구현 1차 검토의 한정 확인 오류를 고쳤다. 지정한 지적과 수정 영향으로 판정 범위를 바꾸고, 확인이 실패해도 원래 유효 지적 목록을 유지한다. 모든 기존 지적을 확인한 경우는 한정 확인 보고에 표시한다. [1차 리뷰](review-records/R1.json) [독립 재현](tester-r2.md)
- 2차 검토를 반영해 상위 검토·확인 전에 본문 표현만 바뀌었으면 확정된 기준이 그대로임을 전후 지문으로 대조한다. 상위 확인은 원래 단계 결과 대신 직전 실패의 원문·변경을 받는다. 같은 진단으로 열린 상위 검토와 해결안 확인은 최대 두 묶음이다. 승인 이후에도 기존 회차와 증거를 보존한다. [2차 리뷰](review-records/R2.json)
- 3차 검토가 지적한 후속 작업 링크를 확인했다. BL261125_01의 BR04 호출 절차 연결 문서는 main 작업본에 추가 상태이며 main 커밋에는 아직 없다. 이 작업본의 브리프에서는 해당 정본을 번호와 제목으로 인용한다. [문서 보완](landing-docs.patch)
- 최초 독립 tester의 제한 샌드박스에서는 로컬 포트 열기가 거부됐다. 집중 시험 105건과 추가 재현 6건은 통과했고, 전체 검사는 환경 오류 뒤 중단했다. 선언된 전체 검사는 작업본에서 별도로 수행한다. [환경 재현](tester-r1-gateway-isolated.log)
