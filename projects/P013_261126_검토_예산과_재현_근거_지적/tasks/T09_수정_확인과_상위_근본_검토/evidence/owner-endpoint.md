# T09 상위 검토 종료점

2026-11-26 허브가 전달한 owner 답변이다. 허브 질문은 “근본 검토를 두 번 해도 실패하면?”이었다. 선택지 (a)는 그때 owner에게 묻는 조치였다.

> a) 문제를 정리해서 보고 해줘

두 차례의 근본 검토와 적용한 해결안 뒤에도 검증이 실패하면 대상과 단위, 일반·공동·수정 확인·상위 검토의 회차별 결과를 묶는다. 각 상위 검토의 근본 원인과 적용한 해결안, 남은 실패의 재현 근거를 연결한다. 기준 조정, 보류, 한 번 더 확인의 선택지와 허브의 추천·이유를 보고한다.

허브가 이어 전달한 발동 조건은 같은 단위에서 `review-note --diagnosis` 원장 진단 또는 허브 수정 확인의 구조 진단 뒤 독립 검증이 다시 실패하는 경우다. 일반·공동·수정 확인 한도가 남아 있어도 즉시 상위 검토를 열고 단위를 보류한다.
