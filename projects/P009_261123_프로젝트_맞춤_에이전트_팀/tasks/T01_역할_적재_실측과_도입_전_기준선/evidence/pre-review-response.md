# 사전 검토 처리

R1 blocking은 Orca 경유 조건·3턴 관찰로 해소, R2 pass 뒤 사용자 비교 저장소 변경으로 전체 재검토했다. R3·R4의 기준선 조건 누락은 수행자·원장·분량·독립 검토·시작 맥락 및 T08 비교 조건을 고정해 R5 pass(blocking 0)로 해소했다.

R5 should_fix S7·S8은 PROJECT 결정 및 counting.md에서 T08 문서 측정의 prompt 적재 경로와 지시 파일 해시 차이 기록으로 반영한다. 이 표본은 팀 문서/역할을 명시적으로 사용하는 효과만 탐색하고 native 역할 적재를 증명하지 않으며, 실제 대상 저장소에서의 native/prompt 적용은 T08 별도 현장 증거로 판정한다. approval/manual의 원장 매핑은 note와 Orca 메시지 근거를 사용하며 없는 CLI 사건 종류를 발명하지 않는다.
