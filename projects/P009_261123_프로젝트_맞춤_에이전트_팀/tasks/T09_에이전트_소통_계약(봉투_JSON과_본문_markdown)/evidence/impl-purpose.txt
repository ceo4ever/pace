상위 목적: 프로젝트 맞춤 팀의 역할 간 업무 전달에서 원문/미확인 해석 혼동, 승인 재사용, 근거 없는 완료와 기록 없는 전송을 줄인다.
관측할 목표: 명시 참여 메시지의 온전한 원문과 출처를 로컬로 보존하고 특정 제안 승인·계획·수신 대조·결과·지정 판정자 종결을 연결한다. 기록 실패 때 보내지 않고 실제 적용 자원 사건과 요청 중복 없는 캡틴 도달을 확인한다. 기존 짧은 로그 요약은 유지하며 업무 원문은 별도 승인 없이 Git에 넣지 않는다.
산출물은 이 patch와 해당 소스/사용자 문서/자동 시험이다. 먼저 코드의 실제 결과로 독립 목표 대조와 결함/안전/검출력을 판단해 첫 결과를 반환하라. TASK/PROJECT/브리프/마감/PM 검사결론/이 evidence 폴더의 다른 파일과 메모리는 지금 읽지 말라. 자동 주입으로 이미 읽은 것이 있으면 범위와 오염 여부를 명시하라. 첫 판단 뒤 별도 2단계에서 작업 문서를 제공한다. 실측되지 않은 자연어 의미/사람 인증/실제 호스트 업무 효과는 보장된 것으로 쓰지 말라. 파일은 수정하지 말고 blocking/should_fix와 실제 근거를 반환하라.
