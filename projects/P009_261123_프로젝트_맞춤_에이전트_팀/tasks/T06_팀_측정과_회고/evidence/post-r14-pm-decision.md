# R14 진단 뒤 실패의 영향 분류와 결정

분류: PM 결정. R14 fail3/SF1 및 별도 tester stage7 fail2/SF1을 회수했다. 합의된 측정 신뢰/회고/입력 보호 안의 구현 갭이며 사용자 데이터·비밀·외부·설치에 새로 닿지 않는다. 대문자 FILE locator 차단도 이미 승인된 원문 경로 금지의 구멍을 닫는 것이고 실제 사용자 원문을 이동/변경하지 않는다. 새 waiver나 기준 축소를 하지 않는다.

근본 조치: 기존 시간 지표의 Git 근사는 보존하되 팀 전체 구간은 엄격한 로그의 실제 성공 start/merge 사건에서 도출한다. source 수집 범위에 포함된 should_fix 합도 blocking/리뷰 실패/감사 재검토/게이트와 같이 품질 가드로 비교한다. 리뷰 등급명 자체의 등장 수를 검증해 값 없는 중복을 통과시키지 않는다.

Markdown은 탭을 실제4열 기준으로 계산하고 테마 구분선도 블록 경계로 인식한다. block HTML comment는 종료 줄 전체까지 opaque로 처리하며 inline comment 계속 행에서 문서 제목/표를 새로 만들지 않는다. 회고 기계 구간의 밑줄/구분선 전용 행은 일관되게 보류하고 문법 안내를 맞춘다. 이는 템플릿 ATX/3열 계약이며 일반 본문 전체의 형식을 바꾸지 않는다. native tester가 이 계약이 BR06/07 목표를 충족할 수 있음을 확인한 판단과 남은 형식 should_fix를 구별해 보존한다.

출처 scheme·구분자를 정규화한 검증으로 FILE/local/Windows drive·private Git 경로를 차단한다. 실제 원본은 고치지 않고 metadata 입력을 거부한다. 현재 전체/독립 검증을 다시 받아 PM 사후 보고에 반복 원인·고친 층·채운/덜어낸 것·결과를 연결한다.
