# R23 보완 판단

공식 검토 R23 blocking 3건과 tester16 blocking 1건은 T06 측정의 의미와 finish 강제성에 대한 정상 구현 누락이다. 기존 목적·기준·실증 보류 합의를 바꾸지 않는다. 실제 병합·설치·외부 전송은 수행하지 않는다.

- 실패만 남은 전달: 실제 도달 0과 해결 여부를 분리한다. 닫힌 수집 범위에서도 failed-only가 남으면 비교 방향을 보류한다. 재시도 후 성공한 요청의 과거 실패 시도만으로 보류하지 않는다.
- 답변 근거: requestId뿐 아니라 영수증에 선언한 reply ID와 응답 시각을 포함하는 기간도 대조한다. 근거 원문을 읽거나 인증을 주장하지 않는다.
- finish 결합: 채택한 팀 프로젝트의 최종 staged Git tree를 자기 자신을 제외한 TEAM-FINISH.json에 기록한다. merge가 대상 커밋의 트리를 대조하고 승인 계획을 SHA에 결합한다. 임시 인덱스로 계산해 실제 인덱스를 바꾸지 않으며, 합성 저장소만 병합 시험한다. 이는 협력적 변경 감지이며 같은 권한 사용자의 의도적 영수증 위조 방지 장치가 아니다.
- 셀 링크: 균형 괄호만으로 목적지와 제목을 숨기지 않는다. 실제 목적지 뒤에는 공백으로 구분한 인용/괄호 제목만 허용한다.

PM 자체 판단이며 계약 변경·비용·사용자 자료 수정은 없다. 별도 검토와 변경 경계 실험으로 확인한 뒤에만 마감한다.
