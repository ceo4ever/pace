# R66 설계 조치 결정 요약

코디네이터가 A를 승인했다. 조회는 공유 영수증의 최초 판독을 모든 용도에 쓰고, 가용성 또는 내용이 달라져도 기존 미확인 총량을 해제하지 않는다. finish는 선언 영수증의 허용 키와 메타데이터 형식을 자동 스테이징 전에 검사한다. 현재 자료가 손상됐거나 원문이 섞여 판정할 수 없으면 원본을 보존하고 거부한다.

입력 판독, 총량에 사용하는 근거, Git에 둘 수 있는 형식, 실제 스테이징된 발표 후보를 각각 대조한다. 첫 판독에서 확인 못한 일반 파일의 조회 결과는 유효한 다른 관측을 보존한다. 시험에는 임시 Git과 합성 요청을 사용한다.
