# Primary structural reference

Read CommonMark 0.31.2, sections 2.1 and 4.6 on 2026-11-24. Lines may end with CR, LF or CRLF; blank lines use ASCII spaces/tabs. HTML declaration block type4 accepts an ASCII letter, so the existing A-Za-z classifier is retained rather than narrowed to uppercase. This supports the current line normalization and does not claim general CommonMark conformance: the documented machine interval remains a bounded root-ATX/three-column format.

Sources: [characters and lines](https://spec.commonmark.org/0.31.2/#characters-and-lines), [HTML blocks](https://spec.commonmark.org/0.31.2/#html-blocks).
