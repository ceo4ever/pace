## 설계

태스크는 T01부터 순서대로 연다. T01의 임시 저장소 작업자 실측과 기준선 정의는 실제 적용 저장소와 분리한다. 업무 문서 저장소는 사용자 지정을 받은 뒤 기준선 작업에 들어간다. T05·T06은 임시 프로젝트에서 장치와 출력 계약을 검증하고, 실제 직렬화·비교·회고는 T08에서 닫는다.

역할은 저장소 소속으로 유지한다. 역할 정의·생성물·공유 잠금은 저장소 및 공통 파일 경계를 검사한다. 호스트 역할 선택은 기존 작업자 실행 권한을 넓히지 않으며, 시작 지시 경로의 도구 권한 적용 여부는 기록한다. 잠금과 질문 로그에는 자격 증명이나 질문 원문을 남기지 않는다. 변경 경로는 보안 리뷰에서 경로 경계, 파일 덮어쓰기, 작업자 권한, 낡은 소유 토큰과 오동작을 확인한다.
