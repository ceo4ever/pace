## 집계 기준과 한계

태스크 구간 평균은 태스크 작업 시간 합÷태스크 수이고, 비교표의 태스크당 작업 시간은 프로젝트 작업 시간÷태스크 수입니다. 작업 시간은 러닝 시간에서 기록된 질의 대기를 뺀 달력 시간입니다. 사건 우선, 과거 기록은 git author 시각 근사입니다. 작업자는 PROJECT의 worktree 경로로 start→finish, 코디네이터는 main 경로로 start→merge(미병합은 조회 시각) 구간을 읽습니다. 코디네이터에는 같은 시간 다른 대화가 섞일 수 있습니다. 기록 삭제·형식 변경에 따른 누락이 가능합니다.

캐시·추론 필드는 도구마다 의미가 달라 더하지 않습니다. Codex는 rollout별 마지막 누적값−구간 전 baseline, Claude/Gemini는 메시지 사용량입니다. 태스크 밖은 프로젝트 합계−태스크 합입니다. 경계 샘플 중복·누적값 감소가 있으면 토큰 차이가 음수일 수 있습니다. 파일 변경은 태그 커밋의 numstat이며 바이너리는 파일 횟수만 셉니다. 생성 중 미커밋 변경·마감/병합 커밋 자신은 다음 재생성 전까지 포함되지 않습니다.
