# T06 사전 검토 대응

교차 Claude의 pass와 허가 범위를 기록했다. 검토된 기준은 보존하고 시험을 보강한다. [기록](../review-records/R1.json)

| 지적 | 조치 |
|---|---|
| F1 | 각 후보를 전용 빈 Git 저장소에서 호출한다. 파일 목록과 HEAD 부재, 사후 핵심어 검색 0건을 확인한다. 도구 접근 기록에서 열람 파일을 확인하고, 호스트 읽기 정책의 성격과 관측 범위를 명시한다. |
| F2 | S-1에서 기존 문구 고정 시험 범위와 별도로 템플릿 공통·보충 문단과 reviewer 검증 표지를 기계적으로 대조한다. 반환 계약·금지 항목·실행 전 대조와 HANDOFF를 독립 reviewer에게 같이 확인받는다. |
| F3 | 격리 입력 `pace-not-a-deployed-model`을 제공자에 전달해 모델 또는 사용권 거부 문구와 종료값을 대조한다. 짧은 제한 시간의 대조 호출을 사용해 시간 초과와 가른다. 기록 원장은 요청·미확인 실제 모델 및 다른 모델 시도 0을 확인한다. |
| F4 | 프로젝트 하네스는 태스크 내부 증거 경로를 관리 범위로 예약한다. 조건부 `scope: worktree`는 프로젝트 구간 집계에 쓰고 실제 호출은 허브도 수행하도록 호출 표에 설명했다. |
