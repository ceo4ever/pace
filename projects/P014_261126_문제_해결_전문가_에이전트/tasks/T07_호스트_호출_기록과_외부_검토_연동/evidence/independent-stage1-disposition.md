# T07 독립 1단계 지적 대응

1단계 후보는 SHA-256 `fea410d3844ddc9562d051d7d23cbbac6cda00f637ebe2e713f789429759173b`다. 독립 tester가 전체 집중 시험 56개와 두 구조적 결함을 관측했다. 독립 reviewer는 후보 파일을 읽었고 상위 폴더의 패치 파일 읽기는 도구 권한에서 거부됐다. 이 단계에서는 TASK나 작성자 판정 없이 결과를 받았다.

- 판정이 먼저 기록되고 참조가 실패하면 다른 판정이 같은 실행을 연결할 수 있었다. 호출 행에 검토 예약의 해시를 먼저 배타적으로 남긴다. 같은 예약과 호출의 관계만 유지한 채 판정과 참조를 진행하며, 참조만 실패하면 동일 결과로 재시도한다. 합성 시험에서 판정 append 뒤 잠금을 잡는 실패를 만들고 경쟁 예약을 거부했다.
- 같은 호스트 식별의 이벤트가 다른 작업 위치에서 도착하면 같은 ID가 두 원장에 기록될 수 있었다. 처음 정한 범위를 Git 로컬 영수증에 고정했다. 늦게 처리되는 호스트 이벤트와 PM 기록을 그 범위에 결속하고, 새로운 턴에서 재사용된 자식은 호스트 `prompt_id`가 다르면 별도 시도다. 같은 시도의 원래 시각·태스크는 보존한다.
- 실제 Claude 훅 세 단계는 [호스트 실행](claude-live.json)에서 식별자 원문을 남기지 않고 한 행으로 결합했다. 독립 tester가 기본으로 상속한 `PACE_AGENT_CHILD`는 설치 시험의 역할 부트를 억제하므로 최종 후보의 관련 검증에서는 테스트 프로세스에 한해 그 환경 변수를 뺀다.
- 다른 원장 위치의 검토는 실제 판정 파일과 해당 호출 기록이 같은 체크아웃에 있어야 한다. 명시 연결 없이 이미 등록한 기존 판정의 판독과 등록 규칙은 유지한다. 신뢰할 수 없는 로컬 쓰기 잠금이나 범위 영수증은 안전을 위해 자동 이동·추정하지 않는다.
