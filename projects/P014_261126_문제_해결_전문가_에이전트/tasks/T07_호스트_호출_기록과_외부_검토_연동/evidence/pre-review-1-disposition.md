# T07 사전 검토 대응

교차 Claude 검토가 구현을 허가했다. 다음 보완을 테스트와 문서에 반영한다.

- 격리 홈의 쓰기 오류와 실제 잠금 경합, 잘린·과대 입력에서도 실행 종료 0과 유한 지연을 확인한다. Git 밖 및 프로젝트로 귀속되지 않는 Git 루트는 행이 없고, 유효 미채택 프로젝트는 호출 행만 남긴다.
- 프롬프트·description·세션·자식 ID·transcript 경로의 구별되는 합성 표지가 정본과 훅 출력에 남지 않음을 확인한다.
- `call-id`는 PM 선행 입력과 뒤따른 훅이 같은 호스트 ID 해시를 사용하게 한다. 호스트 이벤트가 먼저 끝난 시각 정보만 주면 처음 관측을 시각의 대리로 쓰고 이후 바꾸지 않는다. 호스트 전체 시작을 측정했다고 표시하지 않는다.
- 실제 Claude 네이티브 반환으로 외부 검토를 연결한다. 불일치·부분 쓰기 실패·재시도는 합성으로 처리한다. `--hand`의 검토 예약과 `--call-id`의 관측 시도는 각 원장에 고유하다. 판정만 성공한 뒤 동일 호출로 연계를 재시도해 검토 판정이 추가되지 않는지 확인한다.
- 검토를 발급했지만 결과를 받지 못한 실패 시도는 참조 없는 실제 행을 대조한다. 호출과 검토 집계의 수치·횟수는 개별 조회 항목에서 확인한다.
