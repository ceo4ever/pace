Claude는 PACE 제품 소스의 훅 명령을 임시 Git 저장소 설정에 넣고 테스트용 역할을 `pace team new` → tier 설정 → `pace team sync`로 생성했다. 구성원은 p 환경의 읽기 전용 픽스처 입력만 받았다. `review-hand`의 고정에서 실제 외부 판정을 받은 다음 `review-record --call-id`와 동일 행 수동 재입력을 실행했다. 신판 stats의 호출 집계는 기존 외부 원장에 있던 미보고 시간/토큰과 분리된다. 설치·제거는 실제 사용자 설정 대신 테스트 홈에서 검사한다. 전체 프로젝트의 실제 역할 원본 적용은 T06이며 최종 대조는 PROJECT-CLOSE에서 수행한다.
