## 목적

팀 구성원이 호스트에서 직접 실행되거나 PM이 외부 검토를 받을 때에도 T03의 호출 원장에 실제 시도당 한 행과 관측 근거를 남긴다. 자동 수집과 PM 입력이 같은 실행을 보강할 수 있어야 한다. T03과 함께 P-7을 확인한다.

## 기준

| # | 완료 기준 |
|---|---|
| T-1 | Claude의 프로젝트·백로그 내 실제 팀 호출을 시작·종료 훅과 Agent 결과로 기록한다. 자식 식별, 모델 보고, 자식 effort, 시간·토큰이 각 정확한 출처를 갖는다. 관측값이 없으면 null·미확인이다. 공개 설치 설정은 PACE가 소유한 훅만 멱등 갱신·제거하며 사용자 훅을 보존한다. 로그에 호스트 ID 원문·프롬프트·응답·비밀이 없고 잘못된 입력과 I/O 문제에서도 호스트가 진행한다(P-7). |
| T-2 | 같은 시도의 시작·종료·보고·PM 수동 기록이 중복 또는 다른 순서로 도착해도 한 행이며 검증된 값과 최초 시작 시각·귀속을 보존한다. 서로 다른 시도는 서로 다른 행이다. Codex 자동을 관측하지 못하면 실제 호스트 호출 1회를 수동 입력 1행과 대조한다. 실패·중단은 직접 확인한 상태와 관측 수치만 남긴다(P-7). |
| T-3 | `review-hand` → 외부 실행 1회 → `review-record --call-id`가 한 시도 행과 하나의 원장 판정을 잇는다. 시간·토큰은 호출 시도의 호스트 보고/PM 값이고 검토 원장에는 기존 값과 판정이 남는다. 다른 프로젝트·태스크·실행이나 이미 연결된 판정으로 참조를 바꿀 수 없고, 두 CLI 명령은 호출로 계수되지 않는다(P-7, P-13). |
| T-4 | 호출 기록 요건 ID와 버전 1을 정본에 등록한다. 실제 팀 픽스처 `pace-troubleshooter` 호출의 요청/실제/출처 다섯 항목과 T03 장치를 대조한다. 실제 P014 원본으로 하는 최종 대조는 PROJECT-CLOSE가 담당한다(P-7, P-12). |

## 접근

- `src/agent/call-hook.ts`와 `src/cli.ts`에서 bounded JSON stdin을 읽는다. Claude `SubagentStart`·`SubagentStop`과 `PostToolUse`의 Agent 결과를 사용한다. 호스트 세션·자식 ID를 도메인 분리 해시로 연결한다. 역할은 저장소 정의로, 요청값은 같은 역할의 해당 호스트 생성물로 확인한다. 생성물 또는 보고 필드가 없으면 미확인이다. 자식 effort는 종료 훅의 수준, 모델과 시간·토큰은 부모에게 도착한 자식 결과에서만 읽는다. 자동이 완료·실패를 확정할 수 없을 때 PM이 알려진 값을 보강한다.
- `src/project/agent-calls.ts`와 `src/agent/call-context.ts`가 잠금 안에서 기존 시도 시각·태스크를 따라 자동 관측을 보강하도록 한다. 첫 관측이 늦은 경우 해당 관측 시각을 시작의 대리로 쓰고 이후 바꾸지 않는다. PM 수동 입력은 같은 ID와 최초 행 시각을 쓴다. 같은 이름의 자식도 호스트 식별이 다르면 구분한다.
- `src/setup/install.ts`는 Claude 전용 훅을 기존 편집·백업·정확한 관리 명령에 결속해 추가한다. 이를 격리 홈에서 시험하고 실제 사용자 홈은 쓰지 않는다. Codex 프로젝트 훅 신뢰는 바꾸지 않으며 현재 미관측 환경은 문서화한 수동 기록을 검증한다. 민감 경로에 대해 [보안 체크리스트](../../../../docs/SECURITY.md)를 적용한다.
- `src/agent/review-hand.ts`에 외부 `review-record --call-id`를 추가한다. 호출과 판정의 대상 범위·구성원·제공자·발급 이후 실행·기존 참조 상태를 대조한다. 판정 등록 뒤 같은 호출에 결과 상대 경로를 보강한다. 미지정 호출은 기존 판정 경로로 동작한다. 보강 실패는 원장 판정과 구별해 알리고 기존 시도·판정 경로로 PM이 재시도할 수 있게 한다.
- `docs/AGENT-CALL.md`·`docs/WORK-PROCESS.md`·`docs/SECURITY.md`에 호스트 등록과 운영 경계를 연결한다. `test/agent-calls*.test.ts`·기존 설치/검토 시험에서 정상·거부를 확인한다. `skills/pace-team/references/required-roles.md`에 TS-06 v1을 등록하고 실제 근거를 대조한다.
