# 독립 1단계 판단 대조

Claude reviewer와 Codex tester에게 먼저 제공된 내용은 목적과 산출물 패치 및 조기·상위 실제 관측 파일이었다. 작업 문서나 행동 채점표는 2단계에서 건넨다. 양쪽이 두 가지 호출과 상위 단계의 일반 재검증 차단을 확인했고 반환 후 운영 분기 전체는 미확인으로 남겼다. [reviewer](review-stage1.json) [tester](test-stage1.json)

- 당시 문구가 세 기회를 같은 ID로 잇는다고 읽힐 수 있었다. 각 기회를 각 실제 시도 ID로 잇도록 수정했다. 세 행과 각 반환, 같은 ID 재입력에서 추가 0행은 격리된 원장 CLI로 확인했다. [W05 합성 기록](joint-route-w05.json)
- 세션은 각각 새 맥락이었으나 격리 저장소가 공용이었다. 조기 반환은 인접 T02 진단을, 상위 반환은 T01 반환을 읽은 사실을 남겼다. 관측은 역할·모델·라우팅과 증거 연결에 한정한다. 당시 입력 자체도 보존했다. 운영 안내는 각 기회의 입력·읽기 범위를 한정한다. 상위의 임시 설계와 백로그 해석은 합성 요청문에서 왔으므로 승인된 별도 정본으로 해석하지 않는다. [조기 입력](actual-early-input.md) [상위 입력](actual-upper-input.md)
- 상위 원장의 작성자·작업자·trigger·slot과 호출 ref 데이터는 2단계에 제공한다. fixture 식별자와 실제 모델의 독립성 범위를 적었다. 조기 반환 기록은 같은 시도의 모델·effort/참조 보강이며 프로젝트 판정 사건은 별개 한 건이다. [근본 검토 근거](root-evidence-fields.json) [조기 로그와 호출](actual-early.json)
- 회귀 대조에서 직전 지적은 verify가 원장에서 넣는다는 사실을 놓치는 응답이 나왔다. 안내는 선택값의 뜻과 근거 작성법을 목적 파일에 넣도록 하고, 직전 기록은 도구에서 자동 제공하도록 고쳤다. 사전 검토 오분류는 B의 재현과 복구를 지키고 구현 취향을 맞추는 검토를 요구하지 않는다. 백로그의 A-1 분기와 일반 정정은 계약 T-4 H 회귀와 함께 대조한다.
- 조기·상위 실제 단계는 전문가 반환과 원장의 연계를 시험했다. 초기 verify 판정은 합성 응답이라 실사용 검토의 검출력으로 확대하지 않는다. 음성 대조·결정·종료와 외부 진입점은 행동 평가 및 P013/T09 도구 시험으로 확인한다. 모델·effort 양쪽 적용은 T06 증거다. 제공자가 보고한 입력 토큰과 총량 미확인은 비용 추정에 쓰지 않는다.
