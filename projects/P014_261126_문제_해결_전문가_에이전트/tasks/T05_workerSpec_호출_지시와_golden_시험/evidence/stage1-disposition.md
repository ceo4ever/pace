# T05 1단계 독립 대조 대응

reviewer와 tester는 시작 지시의 세 분기와 구조화 판정 보존에 같은 방향의 근거를 확인했다. 작업 문서를 받기 전 선택 표지의 실제 작성 경로를 미확인으로 남겼다. [reviewer](reviewer-stage1.json) [tester](tester-stage1.json)

- 상위 검토·소진 우선순위와 같은 검토 회차의 복수 신호를 한 기회로 세는 규칙을 시작 지시에 명시했다. 일반 산출물의 `review_failures` 분기 및 직접 호출·허브 반환은 기존 정본 절로 연결한다.
- T05는 두 역할이 낸 보조 표지를 구조화 판정 자료로 보존하는 경로를 만든다. 반환을 요청하는 지침과 실측은 BR04가 맡는다. 보조값으로 강제로 신호를 생성하면 T02 장치와 기존 검토 동작을 바꾸므로 기존 신호 계산을 유지한다.
- 원장 판정이 같은지 비교하는 시험에 세 가지 적용 등급을 모두 포함했다. 소진과 상위 검토에서 근거 인계 및 직접 호출·결정 금지도 별도로 단언한다.
