# 프로젝트 보안 지적 처리

독립 초기 검토는 각 태스크 구현 패치와 실제 파일을 읽어 Claude 호출 훅의 구버전 실행기 경계와 H01 증거의 로컬 사용자 경로를 지적했다. 후속 검토에는 main 이후 전체 제품 diff, 고정 T04 문서 diff 및 설치기 수정분을 별도로 제공했다. [초기 판단](security-initial.md) [후속 판단](security-delta.md)

- S1을 반영했다. 구버전의 호출 명령 거부로 종료 2가 나오는 상황을 임시 실행기로 재현했다. 새로 등록하는 관측 훅은 호스트에 출력을 보내지 않고 종료 0으로 마친다. 기존 설치·제거에는 두 정확한 관리 문자열만 적용한다. 이전 관리 문자열의 교체·제거, 작은따옴표가 있는 경로, 사용자 훅 보존, 현재 호출 원장 정상 동작을 검증했다. [수정분](security-rollback.patch) [타입 검사와 집중 검사](security-rollback-check.txt)
- S2를 반영했다. H01과 최종 평가의 저장 증거에서 호스트 홈·임시 절대 경로를 가렸다. 반환 내용과 사례·사본 해시는 보존했다. 보안 검사를 모든 최종 증거에 적용한다.
- 후속 검토의 blocking·should_fix는 각 0건이다. 관리 훅을 모르는 구판 제거기는 등록을 남길 수 있고, 남은 새 훅은 오류를 호스트에 보내지 않는다. Windows 실기와 실제 설치본 교체는 관측하지 않았다. 역할의 prompt 및 권한 상속·로컬 메타데이터와 누락 한계는 기존 보안 정본과 운영 인계에 남겼다.
