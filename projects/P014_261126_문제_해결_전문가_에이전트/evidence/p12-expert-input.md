# P014 마감 전 실제 문제 해결자 호출

호출 PM은 P014 worktree에서 두 필수 역할의 공동 목표 종결 근거를 검토한다. 역할과 읽기 전용 범위를 확인했다. 지정 Codex 최상위 설정의 실제 호출로 BR03 원장 증거를 만든다.

막힌 목표는 먼저 이전 두 조기 신호의 증거와 전문가 반환이 실제 반복 부류를 확인하는 데 충분한지 판단하는 것이다. 실패 원문 두 회차는 격리 fixture에서 만들어졌고 실제 'verify'로 라우팅했다. 이 제품 코드에는 그 fixture 기능이 없다. 운영 조치를 제안하거나 실행할 필요는 없으며, 시험 증거의 의미와 강해질 근거를 돌려 달라.

읽기는 아래 자료만 사용한다. 실제 종료 판정, 게이트 실행, 파일 변경, 저장소 밖 조회는 범위 밖이다. 사용자 결정이 실제로 필요한 때만 HANDOFF의 선택지와 근거로 남긴다.

- T04 evidence/actual-early-input.md 및 actual-early-response.md의 반복 경계, T04 evidence/actual-upper-input.md의 두 차단 판정과 세 층.
