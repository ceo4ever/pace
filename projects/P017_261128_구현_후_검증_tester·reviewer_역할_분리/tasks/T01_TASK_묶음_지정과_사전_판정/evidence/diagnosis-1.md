# T01 사전 검토 구조 진단 1

- 증상: S-7 (나) 성공 조건이 R2 F5·R3 F7·R4 F8·R5 F9로 네 번 연속 blocking(범주 detection, 위치 TASK.md:50).
- 원인 층: 설계(시험 설계). (나)는 음성 대조라 두 관측 — 도구 계산 판정 pass(다른 범주 blocking·증거 공백 배제)와 reviewer 범주 지적 0건(등급 무관, 잘못된 필요·생략 지적 배제) — 을 함께 요구해야 하는데 회차마다 한쪽만 적었다. F5·F7·F8은 판정 쪽, F9는 지적 쪽 누락.
- 반증: F9 재현은 reviewer 범주 should_fix가 pass를 유지하는 분기(structured-review.ts:221-234)로, 판정 조건만으로 막을 수 없다. 지적 조건만으로는 F8(다른 범주 blocking fail)을 막을 수 없다. 결합만이 두 반례를 모두 거른다.
- 해결안(허브 승인, main 판단 2026-11-28): (나) 성공 조건 = "도구 계산 판정 pass이고 reviewer 범주 지적(등급 무관) 0건". BR01 행동 평가 (가)(나)(다) 유지라 A-1 아님.
- 수정 영향: TASK.md:50 S-7 기대 결과의 (나) 조건 문구만.
