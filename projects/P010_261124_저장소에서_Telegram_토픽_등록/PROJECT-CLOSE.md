# P010 저장소에서 Telegram 토픽 등록 — 마감

- 프로젝트 [PROJECT.md](PROJECT.md) · 마감 2026-11-24

## 목표 달성 판정

현재 Git 저장소에서 토픽 등록을 요청하면 승인한 한 번의 로컬 명령으로 루트 등록, daemon 설정, 읽기 전용 Telegram 토픽을 연결한다. 시험에서는 저장소 하위 폴더에서 시작해 해당 토픽의 첫 조회가 저장소 표식에 답하는지와 실행 중 복구 경계를 대조했다.

실제 포럼의 1차에서는 토픽 관리 권한 거절을 확인했다. 2차에서는 수동 결속과 읽기 전용 첫 조회를 검증했고, 기존 결속과 CLI 표시가 어긋나는 경우를 발견해 수정했다. 마지막 실제 시험에서는 승인한 한 번의 add가 토픽 하나를 자동 생성했고 그 토픽의 첫 표식에 읽기 전용으로 정확히 응답했다. 재요청은 기존 결속을 표시했다. 이 시험은 해당 Mac의 격리 CLI와 daemon 프로세스에 IPv4 우선 옵션을 적용한 조건에서 통과했다.

## 보안

- 활성 등록의 ID, 승인한 실경로와 파일 신원을 설정 반영 및 작업 수락에 대조한다. Gateway는 로컬 토큰 인증과 Origin 검사를 유지한다.
- 생성 전 확인한 포럼과 daemon 대상을 대조하고 기존 결속을 해당 포럼에 묶는다. 미허용 채팅·사용자 요청을 거절하고 새 연결은 읽기 전용으로 연다.
- 로컬 계획에서 승인에 필요한 경로와 대상 포럼을 표시한다. 완료·실패 출력, Telegram 본문과 로그의 경로·토큰·원격 식별자는 격리 시험으로 대조했다. 마감의 선언된 보안 검사도 적용한다.

## 남은 일

사용자 승인 아래 main에서 병합하고 실제 설치와 roblox-studio 등록을 인수한다. 시험 Mac에서 Node 기본 연결은 시간 초과와 IPv6 도달 불가를 보였다. 실측은 시험 CLI와 daemon에 한해서 `NODE_OPTIONS=--dns-result-order=ipv4first --no-network-family-autoselection`을 적용했다. 기본 연결 상태는 운영 인수에서 확인한다.

## 회고

격리 API 시험은 호출 수, 생성 의도와 상태 롤백을 재현했다. 실제 포럼 시험은 봇 권한과 기존 결속 표시 문제를 드러냈다. 생성 결과를 확인할 수 없을 때에는 다음 시험이 원인을 대조할 수 있도록 응답 원문에서 분리된 고정 코드를 기록한다.
