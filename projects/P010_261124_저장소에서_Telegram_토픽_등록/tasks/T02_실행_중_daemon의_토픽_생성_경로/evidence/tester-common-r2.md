## 기존 단언과 남은 확인

- HEAD `5b373f3` 대비 `daemon-workspace`·`telegram-flow`의 기존 단언은 유지됐다. `telegram-format` F-8·F-9는 기존 경로 포함 사용법의 HTML 서식과 평문 복원을 유지하면서 경로 없는 사용법을 추가로 단언한다. `telegram-use` N-1은 토픽 관리 권한·포럼 꺼짐 안내와 같은 명령 재시도를 유지하고, 미분류 오류는 고정 실패 안내와 원문·경로 비노출을 확인한다. 모의 API의 기본 토픽 시작 번호도 유지됐다. 공통 계약의 기존 단언 약화는 확인되지 않았다.
- 경로 포함 `/new`는 기존 허용·거부·재시도 회귀만 확인했다. 최종 권한 판정과 실제 Telegram 포럼에서 자연어 요청부터 첫 조회까지의 S-5/P-5 증거는 미결이다.
- 비노출 검사는 지정 시나리오에서 수집한 출력과 새 포럼 메시지를 대상으로 한다. 재기동 시험은 정상 정지 후 재시작이며, 전체 저장소 검사와 실제 Telegram 전송은 이번 실행 범위 밖이다.
