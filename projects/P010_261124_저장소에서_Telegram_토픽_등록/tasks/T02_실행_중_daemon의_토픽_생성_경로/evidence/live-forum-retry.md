# P-5 실제 포럼 시험 2차

- 실행·확인 주체는 코디네이터(main)다. 승인된 시험 포럼의 기존 관리자 봇에 토픽 관리 권한만 켜고, 저장 후 화면을 다시 열어 확인했다. 1차에서 승인받은 격리 환경을 다시 사용했다.
- CLI는 등록된 루트를 재사용하고 daemon 설정을 반영했다. 토픽 생성은 결과 불명과 `/bind` 안내를 반환했고 생성 의도 한 건이 남았다. Telegram 화면을 다시 불러왔을 때 대상 토픽은 보이지 않았다. 그때의 API 응답이나 어느 코드 분기가 결과 불명을 반환했는지 판별할 근거는 확보하지 못했다.
- main은 승인된 시험 토픽 하나를 UI에서 만들고 같은 토픽에서 `/bind`를 실행했다. 첫 표식 조회는 Claude ACP가 읽기 전용으로 실행했고 정확한 표식으로 응답했다. 결속과 등록의 ID 일치, 결속 한 건, 생성 의도 제거를 확인했다.
- 같은 CLI 요청을 다시 실행하자 포럼 대조에 실패했고 출력은 미결속을 표시했다. 실제 결속과 토픽 한 건은 유지됐다. 이 표시는 모의 API로 재현해 수정했다. 수정된 CLI는 기존 결속과 포럼 대조 실패를 함께 표시한다.
- main은 로컬 경로·토큰·채팅 및 토픽 식별자 비노출, 격리 시크릿 사본 제거, 운영 daemon 복구를 확인했다.
- 수동 결속 복구와 실제 첫 조회는 확인됐다. 한 번의 승인된 CLI 요청이 실제 토픽을 자동 생성하고 그 토픽에서 첫 조회가 성공하는 과정은 재시험을 기다린다.
