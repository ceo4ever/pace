# P-5 실제 포럼 시험 1차

- 실행·확인 주체: 코디네이터(main). 사용자 승인 뒤 임시 PACE_HOME과 미등록 Git 저장소로 실행했다.
- 진입: 새 Codex 세션을 시험 저장소의 하위 폴더에서 열어 "이 저장소 Telegram 토픽 등록해줘"라고 요청했다. 경로를 생략한 CLI가 Git 최상위, 신규 활성 등록, AGENT 생성 계획을 표시했다.
- 승인: 시험 포럼 이름과 read-only를 확인하고 대화형으로 승인했다. main은 유효한 AGENT, 일치하는 등록 ID와 Git 최상위 경로의 daemon 설정 반영을 대조했다.
- 결과: Telegram이 봇의 토픽 관리 권한 부족으로 생성을 명시적으로 거절했다. 결속과 생성 의도는 남지 않았다. 토픽에서 첫 조회하는 단계는 실행하지 못했다.
- 비노출·복구: main은 시험 로그에 로컬 경로와 봇 토큰이 드러나지 않았음을 확인했다. 임시 시크릿 사본 정리와 기존 운영 daemon의 실행 복구도 확인했다.
- 판정: P-5 미완료. 봇 권한 후속 및 승인된 재시험은 main이 맡는다. 토픽 결속, 정확한 저장소 표식의 첫 조회, 해당 출력의 비노출을 증거로 받아 대조한다.
