## 1단계 독립 목표 대조

**읽은 범위**
- 프롬프트에 포함된 diff 전체를 읽었다.
- 저장소 파일은 `src/daemon/config.ts`의 `WORKSPACE_NAME` 정의 한 줄만 읽었다.
- 작업 문서(TASK·테스트 표·자체 판정)는 읽지 않았다.
- 파일을 고치지 않았고, 운영 서비스와 사용자 홈에는 접근하지 않았다.
- 세션 시작 맥락(CLAUDE.md, AGENTS.md, gitStatus, 사용자 이메일)이 호스트 첨부로 노출돼 있었다. 판정에는 쓰지 않았다.
- 읽기 전용이라는 것이 완전한 격리를 뜻하지는 않는다.

**독립 목표 대조**

| 항목 | 판단 | 근거 |
|---|---|---|
| General은 `/new <이름>`만 지원 | 달성 | `newCommand`가 `WORKSPACE_NAME`(앵커된 `^[A-Za-z0-9][A-Za-z0-9_.-]{0,39}$`)에 전체 입력을 맞춘다. 공백·`/`·`~`·따옴표가 들어간 입력은 모두 탈락한다. |
| 그 밖의 입력은 도움말만 | 달성 | 탈락한 입력에는 고정 문구(사용법과 `LOCAL_WORKSPACE_ADD`)만 보낸다. `validate`, `workspaces()` 조회, 설정 쓰기, 의도(provisioning) 기록, 토픽 생성이 모두 그 앞에서 끝난다. S-9g가 `validates==0`, `lookups==0`, 설정·상태 불변, 경로 비반사를 단언한다. |
| 입력 경로 비반사 | 달성 | 이름 형식을 통과한 값만 "등록된 워크스페이스가 아니다: ${rest}"로 되돌려 보낸다. 이 값은 경로가 될 수 없다. 생성 거절 문구도 Telegram 원문 대신 상태 코드로 고정했고, `commit_failed` 로그에서도 오류 원문을 뺐다. |
| 로컬 CLI·Gateway 승인 등록 유지 | 달성 | `registerWorkspace` 경로와 `--yes` 승인 모델은 그대로다. Gateway에는 `forum` 검증(64자 hex)과 `forumProof` 대조(토큰 포함)를 더했다. 포럼을 확인하지 못하면 설정만 반영하고 토픽은 만들지 않는다. |
| 조회·쓰기 승인 보존 | 달성 | `/write`는 승인 요청 단계에서 멈추고 `runAccess`는 `read-only`만 남는다는 테스트가 있다. 코어의 승인 로직은 건드리지 않았다. |
| 중복 없는 토픽 복구 | 달성 | `topicRequests`로 같은 이름의 동시 요청을 합치고, 생성 호출 전에 의도를 디스크에 쓴다. 의도에는 `registryId`를 기록한다. 응답이 유실되거나 재기동한 뒤에도 재발행하지 않고 `/bind`로 안내한다. 등록 ID가 다른 의도는 `conflict`로 거부한다. 테스트가 이를 모두 확인한다. |
| 테스트 비약화 | 달성 | 삭제된 S-20c와 `registerLegacyWorkspace`는 제거된 코드에 대한 테스트다. S-9g는 더 강한 부정 단언으로 바뀌었다. S-9k의 "h가 설정에 남는다" 반전은 설계 변경(General은 설정을 쓰지 않음)에 맞춘 것이라 약화가 아니다. 고유 단언을 새로 더했다. |

**목표 달성: 달성** (코드와 diff 기준. 테스트를 실제로 실행하지는 않았다. P-5 실제 확인은 사용자 승인 대기다.)

**전략에 다른 길이 있었는가**
- General `/new`를 완전히 없애는 길도 있었다. 하지만 사용자 결정이 `/new <이름>` 유지이므로 현재 길이 맞다.
- 토픽 생성 경로를 Gateway와 General이 `ensureWorkspaceTopic` 하나로 합쳤다. 이중 구현보다 낫다.

**지적**
1. **note**: 이 버전으로 처음 기동하면, `forumKey`가 없는 기존 상태가 현재 설정의 포럼에 귀속된다(`adapter.ts`의 `!loaded.forumKey && this.o.forumKey` 분기). 이미 포럼을 바꾼 운영자에게는 잘못된 귀속이 생길 수 있다. `docs/DAEMON.md`에 경고가 있어 추적은 되지만, 자동으로 막지는 못한다.
2. **note**: 형식을 통과한 이름은 그대로 답장에 반사된다. 40자 이내 영숫자라 경로 위험은 없다. 다만 토큰 모양과 우연히 겹칠 수 있어, 방어를 겹치고 싶다면 `redact`를 적용할 수 있다. 현재 요구 범위 안에서는 문제가 아니다.
3. **note**: Gateway 대기 시간이 38초로 늘었다(`workspace-cli.ts`). 생성 호출 지연을 수용하는 의도로 보이며 목표와 충돌하지 않는다.
