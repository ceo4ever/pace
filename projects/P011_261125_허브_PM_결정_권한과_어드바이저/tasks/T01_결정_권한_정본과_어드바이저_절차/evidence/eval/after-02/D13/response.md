## 사례 1: TASK 검토 (구현 전 검토)

- **담당**: 워크트리 PM이 호출하고 판정한다. 검토자는 별도 reviewer다. 근거는 `task-steps.md` 2단계 "구현 전 검토"와 "reviewer 배정"이다.
- **순서**
  1. 작성자와 다른 제공자를 먼저 호출한다. 예: Claude PM이면 Codex. 호출에 실패하면 종료 코드 10(미실행)과 사유를 기록한다.
  2. B1(기존 위임)에 따라 같은 제공자의 새 세션으로 검토한다. 이 호출에는 `--allow-same-provider`를 쓰거나 호스트의 별도 새 세션을 쓴다. 결과에는 `cross: false`를 기록한다.
  3. 아래는 실제로 실행할 명령 형태이며 이번 시험에서는 실행하지 않는다.
     ```
     pace agent verify --author-agent <claude|codex> --target TASK.md \
       --purpose-file <상위 목적> --out <기록> --allow-same-provider
     ```
  4. blocking이 있으면 고친 뒤 `verify`를 다시 호출한다. pass(blocking 0)이면 구현한다. should_fix는 반영하거나 이유를 남긴다. 목적·범위가 바뀌면 §6에 따라 묻는다.
  5. 기록은 TASK 기록에 대상, 판정, 지적 처리, 검토 방식(`cross: false`, 미실행 사유)을 남긴다.
- **질문·승인 대기**: 0건. B1은 A-3의 "아니오"에 해당하므로 owner에게 묻지 않는다. 같은 제공자 검토를 진행한다.

## 사례 2: 백로그 검토

- **담당**: 백로그 작성 PM이 호출하고 판정한다. 근거는 `cross-verify.md`와 B1이다.
- **순서**
  1. 다른 제공자를 먼저 시도한다. 호스트가 직접 호출할 수 있으면 그 기능을 쓰고, 없으면 `pace agent verify`를 쓴다.
  2. 호출이 불가능하면 미실행 사유를 기록한다. 그 뒤 `--allow-same-provider`로 같은 제공자의 새 세션을 열어 상위 목적 우선으로 검토한다. 결과에는 `cross: false`를 기록한다.
  3. 지적은 blocking, should_fix, note 등급으로 온다. 작성자가 항목마다 반영 여부와 이유를 남긴다. 목표·전략 이견은 A-1로 판정한다.
  4. 백로그 원본 문서를 직접 편집했다면 커밋 전에 `pace backlog refresh`를 실행한다.
- **질문·승인 대기**: 0건.

## 사례 3: 둘 다 호출할 수 없는 경우

이 경우는 다른 제공자와 같은 제공자의 새 세션이 모두 미실행인 때다. 검토 자체를 생략하는 것이므로 A-3에 해당한다.

- **담당**: PM이 `ask`로 허브에 인계하고, 허브가 owner에게 C의 결정 요청을 보낸다. 단독 PM이면 직접 보낸다.
- **순서**
  1. 두 경로의 미실행 사유를 기록한다.
  2. owner에게 "A-3" 번호를 붙여 요청한다. 요청에는 대상, 근거, 선택지, 추천과 이유를 담는다.
  3. TASK는 사전 검토 관문을 보류한다. 해당 조치만 보류하고 독립 작업은 이어간다.
  4. 검토가 한 번도 실행되지 않았으므로 PRE-REVIEW `waiver`는 성립하지 않는다. 사용자가 답을 줘도 `waiver`를 임의로 붙이지 않는다. 현재 계약과 게이트 요건을 먼저 확인한다.
  5. 답을 받으면 승인 원문과 출처를 근거 파일에 연결한다. `waiver`의 `by: user`는 워크트리 PM이 현재 대상과 해시를 대조한 뒤 입력한다.
- **질문·승인 대기**: 사례마다 1건이다. 질문은 owner에게 보내는 A-3 결정 요청이다. 검토 게이트(구현 전 검토 또는 백로그 검토)는 답이 올 때까지 보류한다.

## 경계

- 다른 제공자를 호출할 수 없다는 이유만으로 owner에게 묻지 않는다.
- 같은 제공자의 새 세션을 다른 제공자 검토인 것처럼 기록하지 않는다. 반드시 `cross: false`로 적는다.
- 실행된 교차 검토가 fail이면 같은 제공자 새 세션으로 대체할 근거가 되지 않는다.
- 이번 시험에서는 수정, 질문, 메모리 기록, 커밋, 전송을 하지 않았다.
