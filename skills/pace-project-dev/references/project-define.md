2. **분석**: 재료를 모은다 — 백로그·코드 위치(`file:line`)·지금 동작·브레인. `new`가 넣어 둔 "- 브레인:" 후보를 열어 보고 관련 없는 줄은 지운다. 부족하면 `pace brain search`로 더 찾는다. 다른 문서는 다시 쓰지 않고 링크한다.
3. **설계**: 목표를 한 단계 위 목적에 대조한 뒤 목적, 기준 `P-n`(실행·관찰로 참·거짓이 갈리는 문장 + 확인 방법), 설계·보안 영향, **바꿀 정본 목록**, 태스크 표. 대조 기준과 수정/질문 원칙은 [goal-review.md](goal-review.md).
