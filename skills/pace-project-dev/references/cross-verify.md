# 교차 검증 (백로그·큰 산출물)

SKILL.md §2에서 옮긴 문서다.

목표 우선의 실제 입력/판단 순서는 [goal-review.md](goal-review.md)를 따른다. 1단계 결과를 회수한 뒤 2단계 작업 문서를 주며, 모든 자료를 한 번에 전달한 순서 지시로 대체하지 않는다.

백로그처럼 큰 산출물은 작성자와 **다른 제공자**의 에이전트가 상위 목적 우선으로 독립 검토한다. 호스트가 직접 다른 제공자 에이전트를 부를 수 있으면 그 기능을 쓰고, 없으면 `pace agent verify --author-agent <claude|codex> --target <파일> --purpose-file <상위 목적 글> --out <기록>`(읽기 전용 `-p`)을 쓴다. 제공자는 결과의 모델·제공자 출처로 판별한다 — 같은 제공자로 몰래 대체하지 않는다.
- 종료 10(미실행)이면 [A-3의 B1](decision-rights.md#a-결정-주체)에 따라 미실행 사유를 기록하고 `--allow-same-provider`로 별도 새 세션을 연다. 결과에 `cross: false`를 기록한다. 양쪽 모두 미실행이면 A-3으로 결정 요청을 한다.
- 지적은 blocking·should_fix·note 등급으로 온다. 작성자가 항목마다 반영 여부와 이유를 남긴다. 목표·전략 이견은 실제 조치가 합의를 바꾸는지 [A-1](decision-rights.md#a-결정-주체)로 판정한다.
