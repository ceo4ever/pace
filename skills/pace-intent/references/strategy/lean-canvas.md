## Looks at

The riskiest parts of a new product, block by block: problem (with existing alternatives), customer segments (with early adopters), unique value proposition, solution, channels, revenue streams, cost structure, key metrics, unfair advantage.

## Key questions

- Are the top three problems real for the first customer segment, and how do they solve them now?
- What single sentence makes a stranger understand why this is different?
- How does the first customer find it (channel), and what do they pay for?
- What does it cost to run per user, and which one number shows it is working?
- What is hard to copy?

## Common gaps

- Problem and solution blocks repeat each other.
- Channels and revenue are blank because the plan focuses on features.
- Key metric is a vanity number (downloads) instead of the job done (videos published per week).

## Turning gaps into questions

Fill blocks from the idea card, JTBD, and alternatives; ask the user only for business choices (price model, first segment). One question at a time, recommending the option the evidence supports.
Example: "수익 모델은? ① 월 구독(추천 — 매일 쓰는 도구라 반복 가치가 큼) ② 생성 건수 과금 ③ 아직 무료로 검증만 — 무료 검증이면 결제 화면을 이번 범위에서 빼요."
If the inputs already say a block is unknown (e.g. an idea card's "아직 모름: 수수료 vs 구독"), do not ask it again — keep it as `미결` with impact and the condition to decide. If the user says it is not for sale (own use), drop this lens.

## Tensions

- With **MoSCoW**: the canvas pushes for a sharp differentiator, MoSCoW pushes for a small first release — ask which differentiator the first release must prove.
- With **purpose ladder**: if the purpose is personal automation, revenue blocks are noise — ask whether selling is a goal now or later.

## When not to use

Internal tools, personal automation, and documents; L1 features inside an existing business model.

## Output form

Form: a block list (블록 · 내용 · 근거/가정/미결), not the canvas layout — each block filled, labelled `가정`, or `미결`.
Link to first layer: JTBD → problem and segments; alternatives → existing alternatives and unfair advantage; assumption map → the riskiest blocks.
When to produce: L2 services for sale and L3 business plans.

## Closing

End with the riskiest block and the cheapest test for it before building — not with a full canvas.
