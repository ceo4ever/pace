## When to make it

Only for use cases whose `sequence` field is set: external system, async or long work, auth delegation, payment, or three or more participants with several failure points.

## First-layer lens questions

Drawing this document exposes these gaps:

- Every external call: what if it fails, times out, or is rejected? (an `alt` with a failure case and an `AC`)
- After async work, how does the user learn it finished?
- Is every external service premise confirmed in official documentation (URL and checked date)? If the provider is not chosen yet, point `docs.open` at an `open` item instead — never invent a URL. The check only confirms that the item exists, not that it is about this provider; name the provider in that item's text.
- Participants stay at user · app · server · queue · external service level — no classes or functions.
