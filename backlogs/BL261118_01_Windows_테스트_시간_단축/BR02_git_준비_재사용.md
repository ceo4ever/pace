# BR02 git 준비 재사용

- 상태: 대기
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

시험마다 반복하는 `git init`·첫 커밋을 한 번 만든 원본 저장소 복사로 바꿔, git 프로세스 기동 비용을 줄인다(위험이 낮은 첫 단축).

## 범위

- 시험 공용 도우미: 시험 실행 시작 때 커밋된 원본 저장소를 한 번 만들고 각 시험은 복사본을 받는다.
- 저장소 준비가 반복되는 시험 파일을 도우미로 옮긴다(BR01 상위 목록 우선).
- 제외: 시험이 검증하는 git 동작 자체(init·commit 경로를 시험하는 경우는 그대로).

## 완료 기준

- 시험끼리 원본을 공유하지 않는다(복사본만 수정) — 서로 간섭 없음을 확인한다.
- 전체 검사 통과·실패 판정이 기준과 같다.
- BR01 측정으로 단축 시간을 기록한다.
