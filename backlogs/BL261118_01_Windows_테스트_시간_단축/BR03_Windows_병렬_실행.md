# BR03 Windows 병렬 실행

- 상태: 대기
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

Windows에서 순차(`--test-concurrency=1`)로 돌리는 시험 파일을 병렬로 돌려 다중 코어를 쓴다 — 가장 큰 단축 후보.

## 범위

- 순차 실행의 원래 이유 조사(이력·브레인·충돌 재현).
- 동시 실행 수 4·8로 각각 여러 번 돌려 불안정·충돌 시험(포트·파일 잠금·전역 상태)을 찾고 원인을 고친다.
- 안정한 값으로 `scripts/test.ts` 기본값 변경, 필요하면 순차가 필요한 파일만 분리.
- 제외: 시험 판정 완화·재시도로 실패 숨기기.

## 완료 기준

- 고른 동시 실행 수로 전체 검사를 반복(최소 5회)해 불안정 실패 0개.
- 순차였던 이유와 처리 결과가 기록돼 있다(브레인).
- BR01 측정으로 단축 시간을 기록한다.
