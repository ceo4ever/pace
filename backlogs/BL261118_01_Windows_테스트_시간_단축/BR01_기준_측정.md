# BR01 기준 측정

- 상태: 대기
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

백로그 목표(전체 검사 시간 절반)의 기준선과 이후 브리프의 효과를 증명할 측정 방법을 만든다.

## 범위

- 환경 실패 없는 상태(symlink 권한·Python)에서 Windows 전체 검사를 같은 조건으로 3회 돌려 총 시간·파일별 시간·시험별 시간을 기록한다.
- 느린 파일·시험 상위 목록과 시간이 어디서 나오는지(프로세스 기동·git·대기) 표본 분석.
- 같은 측정을 다시 돌리는 스크립트 또는 명령(이후 브리프가 재사용).
- 제외: 시험 코드·실행기 변경.

## 완료 기준

- 기준 시간(3회 중앙값)과 실패 0개(환경 실패 없음)가 기록돼 있다.
- 느린 상위 파일·시험 목록과 원인 분류가 있다.
- 측정 명령 하나로 같은 표를 다시 만들 수 있다.
