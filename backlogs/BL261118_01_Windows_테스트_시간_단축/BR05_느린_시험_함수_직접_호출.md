# BR05 느린 시험 함수 직접 호출

- 상태: 완료
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

로직을 확인하는 시험이 CLI를 새 프로세스로 띄우는 대신 함수를 직접 불러 프로세스 기동 비용을 없앤다.

## 범위

- BR01의 느린 상위 파일부터 CLI 호출을 함수 직접 호출로 바꾼다.
- 명령 해석·종료 코드·출력 경로는 대표 CLI 시험으로 남긴다.
- 멈춤 조건: 백로그 목표 시간에 닿거나 남은 대상의 효과가 작으면 멈춘다(364곳 전부가 목표 아님).
- 제외: 동작 변경, 시험 판정 완화.

## 완료 기준

- 바꾼 시험이 같은 동작을 검증한다(바꾸기 전 실패 주입으로 여전히 잡히는지 표본 확인).
- CLI 경로 대표 시험이 명령별로 남아 있다.
- BR01 측정으로 단축 시간을 기록한다.
