# BR04 빠른 검사 명령

- 상태: 완료
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

다른 Git 저장소에서 프로젝트 개발을 할 때도 설치된 PACE가 변경에 관련된 시험을 골라 실행하게 한다. PACE 자체 저장소의 반복 검증 시간 단축과 별개로 제품 사용성을 검증하며, 전체 검사는 `finish`·하네스가 계속 맡는다.

## 범위

- 다른 Git 저장소에서 설치된 PACE CLI로 변경 기반 빠른 검사를 실행한다. 기존 `pace test`·`.pace/test-map.json`을 우선 재사용하고 해당 프로젝트가 선언한 검사·지원 러너를 존중한다. 명령 이름과 프로젝트별 타입 검사 연결은 T04 설계에서 결정한다.
- 바뀐 파일(git 변경 기준) → 관련 시험 선택 → 프로젝트에 맞는 검사 실행. PACE 저장소의 npm 명령은 필요하면 공용 CLI의 얇은 진입점 또는 사용 예로 둔다.
- 선택 근거 출력(어떤 시험을 왜 골랐는지). 공통·미분류 변경 등으로 범위를 확정할 수 없으면 해당 프로젝트의 전체 검사로 전환한다. 전체 검사도 확인할 수 없으면 성공과 구별한다.
- `pace-project-dev` 스킬·AGENTS.md와 사용자 문서에 다른 저장소의 채택 방법을 기록한다.
- 제외: `finish`·하네스의 전체 검사 대체.

## 완료 기준

- 대표 변경 몇 가지에서 관련 시험이 빠짐없이 선택된다(누락 대조 시험).
- 독립 Git 샘플 저장소에서 제품 CLI의 선택 실행·전체 전환·전체 검사 확인 불가 판정을 검증한다.
- 작업 중 검사 시간이 BR01 기준보다 크게 짧다(측정 기록).
- `finish`는 여전히 전체 검사를 돈다.
