# BR04 빠른 검사 명령

- 상태: 대기
- 백로그: [Windows 테스트 시간 단축](BACKLOG.md)

## 목적

작업 중에는 바뀐 파일과 관련된 시험만 돌리는 명령을 두어 반복 검증을 수 분 안으로 줄이고, 전체 검사는 `finish`·하네스가 맡게 한다.

## 범위

- 바뀐 파일(git 변경 기준) → 관련 시험 파일 선택(import 관계 등) → 타입 검사 + 선택 시험 실행하는 명령(예: `npm run check:quick`).
- 선택 근거 출력(어떤 시험을 왜 골랐는지), 고를 수 없으면 전체로 안전하게 넘어감.
- `pace-project-dev` 스킬·AGENTS.md 안내 갱신.
- 제외: `finish`·하네스의 전체 검사 대체.

## 완료 기준

- 대표 변경 몇 가지에서 관련 시험이 빠짐없이 선택된다(누락 대조 시험).
- 작업 중 검사 시간이 BR01 기준보다 크게 짧다(측정 기록).
- `finish`는 여전히 전체 검사를 돈다.
