# BR06 허브 직접 수행 절차와 브레인 정리

- 상태: 대기
- 백로그: [허브 PM main 직접 프로젝트 하네스 정비](BACKLOG.md)

## 목적

허브 PM이 직접 수행할 때의 절차를 스킬 정본에 한 번에 정리하고, 바뀐 결정을 브레인에 반영해 다음 세션이 기억이 아니라 문서로 따르게 한다.

## 범위

- `AGENTS.md`의 작업 규칙("작은 일이 아니면 프로젝트로 — worktree에서…")에 허브 PM 직접 수행 시 main 프로젝트 경로와 적용 조건을 넣는다(저장소 규칙과 CLI 경로 일치).
- `skills/pace-project-dev/`: SKILL.md §1(규모·진행 위치)·§2(main 착수)·§4(main 마감), `references/verification.md`(한 PM 두 역할일 때 검증 소유자와 별도 세션 배정), `references/finish.md`.
- 진행 중 빠진 기록을 알려 주는 점검(예: `pace project list`나 별도 명령에 상태·log·테스트 표·검토·memory status 누락 표시) — BR01~BR05로 충분하면 생략하고 이유를 남긴다.
- 브레인: `brain-at-project-gates`의 "한계(main 직접은 커밋 전 변경만)" 갱신, `작업-하네스-실측-함정`의 "main 직접 마감 순서" 갱신, `작업-하네스-흐름`에 main 직접 경로 추가.
- 프로젝트 메모리 정리: 이슈 `main-직접-finish-브레인-반영-검사-모순`, 아이디어 `main-직접-프로젝트-착수-기록` 닫기.

## 완료 기준

- 스킬만 읽고 main 직접 프로젝트를 착수→마감까지 진행할 수 있다(독립 세션 시범 1회, 결과와 AGENTS.md·스킬 대조 기록).
- 브레인 lint 오류 0, 관련 페이지가 새 동작과 맞다.
- 관련 메모리 이슈·아이디어가 닫혀 있다.
