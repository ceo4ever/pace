# 상위 목적 (출처: 캡틴 대화 2026-11-18)

PACE는 LLM CLI 세션에 올라오는 개인 비서 에이전트이고, 프로젝트는 "작업 하네스"(스킬 pace-project-dev의 절차 + `pace project` CLI의 게이트·기록)로 진행한다. 원칙: 기억이 아니라 계약·게이트·기록으로 진행하고, 완료는 검증으로 증명하며, 검증자·tester는 구현자와 다른 별도 에이전트 세션이 맡는다.

캡틴의 요구: 허브 PM(main 세션 코디네이터, 예: 알투)이 프로젝트를 직접 수행할 때 문제가 많았다(기록 누락, 마감 불가 등). 허브가 직접 수행할 때는 worktree를 만들지 않고 main에 프로젝트를 만들어 하네스를 적용하게 하고, 검증자·tester는 별도 에이전트 세션이 수행하게 하라.
