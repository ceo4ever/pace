# BR05 main 점유 충돌 방지

- 상태: 대기
- 백로그: [허브 PM main 직접 프로젝트 하네스 정비](BACKLOG.md)

## 목적

main 직접 프로젝트가 다른 worktree 프로젝트의 병합(fast-forward)과 부딪히지 않게, main 점유 규칙을 하네스가 판정한다.

## 범위

- `병합 대기` 프로젝트가 있으면 `start --main`과 main 직접 프로젝트 커밋(BR03 게이트)을 막고 이유를 알린다.
- main 직접 프로젝트는 동시에 하나만 `진행`.
- main 직접 프로젝트가 `진행`일 때 다른 프로젝트의 `merge`를 막는다(공통 계약 3).
- 충돌(점유 중 병합이 꼭 필요 등) 때 main 직접 프로젝트를 `보류`로 두고 재개하는 조건·절차(재개 시 변경 집합·검토 대상 재확인).
- 제외: 일반 main 커밋(작은 일·메모리) 정책 변경 — 기존 "병합 대기 중 main 커밋 금지" 규칙은 그대로.

## 완료 기준

- 병합 대기 프로젝트가 있을 때 main 직접 착수·커밋이 막힌다(시험).
- main 직접 프로젝트 두 개를 동시에 진행할 수 없다(시험).
- main 직접 프로젝트 진행 중 다른 프로젝트 merge가 막힌다(시험).
- 보류 중 다른 병합은 허용되고, 재개 때 변경 집합 내용 해시가 달라졌으면 재검토가 요구되며 같으면 그대로 재개된다(시험).
