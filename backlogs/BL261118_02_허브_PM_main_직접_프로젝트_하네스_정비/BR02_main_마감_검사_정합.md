# BR02 main 마감 검사 정합

- 상태: 대기
- 백로그: [허브 PM main 직접 프로젝트 하네스 정비](BACKLOG.md)

## 목적

main 직접 finish가 worktree finish와 같은 검사를 하게 해, 브레인·정본을 고친 main 직접 프로젝트도 하네스로 마감되게 한다(P003 finish 불가 해소).

## 범위

- main 직접 finish는 BACKLOG 공통 계약의 **변경 집합**(시작 커밋 이후 프로젝트 태그 커밋의 파일 + 미커밋 변경)을 프로젝트 변경으로 본다.
- 이 변경 집합으로 브레인 행(`harness.ts:1324`), 정본 반영 diff(`:1331`, 지금은 건너뜀), 의존성 감사(`:1364`, 지금은 생략) 검사를 적용한다. "반영" 판정은 공통 계약 2-0 — 변경 집합 경로 중 시작 커밋 대비 마감 시점에 순변경이 남은 경로만 인정한다.
- 프로젝트 밖 미커밋 금지(`:1259`)는 유지 — 구현을 먼저 커밋하는 순서와 모순이 없어진다.
- 태그 없는 커밋(메모리·백로그 등)과 다른 프로젝트 커밋은 변경 집합에서 뺀다(공통 계약 1·2).
- 제외: worktree finish 동작 변경.

## 완료 기준

- 구현·브레인 변경을 먼저 커밋한 main 직접 프로젝트가 finish를 통과한다(P003 재현 시나리오 시험).
- 정본 목록의 경로가 바뀌지 않았으면 main 직접 finish도 실패한다(시험).
- 태그 커밋으로 고친 정본·브레인을 다른 커밋이 되돌려 순변경이 없으면 "반영"으로 인정하지 않고 finish가 실패한다(시험).
- 다른 프로젝트 커밋·태그 없는 커밋이 섞여도 이 프로젝트 변경으로 세지 않는다(시험).
- 정본 "해당 없음" 처리와 의존성 감사(선언됐고 잠금 파일이 변경 집합에 있을 때 실행, 아니면 생략 사유 출력)가 worktree finish와 같다(시험).
