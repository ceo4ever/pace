## 목표

이 PC에서 PACE daemon을 실제로 쓸 수 있게 한다 — 메신저(Telegram)로 보낸 요청을 daemon이 받아 등록된 워크스페이스의 워크트리에서 에이전트 체인으로 실행하고 결과를 돌려준다. 상위 목적: 자리에 없을 때도 PACE에게 조회·작업을 맡긴다.

**지금 상태(2026-11-16 실측):** `pace daemon status` → `running: false`(인스턴스 포트 55545). `pace daemon install`(계획만) → "에이전트 체인(default)이 없다", 시작 항목 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`의 "PACE Daemon"(`wscript.exe … daemon-launch.vbs`, 관리자 권한 불필요) 등록 예정. Telegram 설정 없음. 코드는 이미 있다 — 설정 마법사(`src/daemon/install-wizard.ts`: 봇 토큰 → 봇 확인 → 그룹 메시지로 chat id·보낸 사람 ID), 쓰기 작업 승인·읽기 전용 기본·비밀 제거(`docs/README.md` 구성 요소 "상시 실행 daemon").

**고른 길:** 새 기능을 만들지 않고 있는 설치 마법사·명령으로 설정한 뒤 실사용으로 검증한다. 막히는 곳만 고친다(이슈·새 백로그).

## 범위

- 포함: 에이전트 체인 설정(BR01), Telegram 봇·채팅·허용 사용자 연결(BR02), 기동·로그온 자동 시작·정지(BR03), 읽기 요청·쓰기 승인·정지 뒤 복구를 실사용으로 검증(BR04).
- 제외: 다른 메신저 어댑터, Gateway 외부 공개, daemon 기능 추가(검증 중 결함은 이슈·새 백로그로).

## 설계 때 정할 것 (사용자 확인)

1. 체인 구성 — `claude`만 / `claude → codex` 대체 순서(한도·실패 시 다음).
2. Telegram — 새 봇을 만들지(BotFather), 개인 채팅 또는 그룹, 허용 사용자.
3. 자동 시작 — 로그온 때 자동 실행 등록(`install --yes --start`) 또는 필요할 때만 `start`.
4. 등록할 워크스페이스와 기본 접근(읽기 전용 기본 유지 권장), 동시 실행 상한(`maxConcurrent` 기본 2).
