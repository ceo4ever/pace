# BR04 실사용 요청 검증

- 상태: 완료
- 백로그: [BL261116_02_PACE_daemon_사용_준비](BACKLOG.md)


## 목적

메신저에서 실제 요청으로 daemon을 끝까지 써 보고, 막히는 곳을 이슈로 남긴다. 목표 달성 판정의 근거다.

## 범위

- 읽기 요청: 등록된 워크스페이스에 대한 조회(예: 진행 상황·메모리 질문) → 응답.
- 쓰기 요청: 승인 메시지 → 승인 → 워크트리에서 실행 → 결과 알림. 승인 만료·거절 동작.
- 정지·재시작 뒤: 이전 승인 무효, 실행 중이던 쓰기 작업이 `needs_review`로 남는지.
- 발견한 결함은 메모리 `issue` 또는 새 백로그로.

## 완료 기준

- 읽기·쓰기(승인) 요청 각 1회 이상 메신저에서 끝까지 성공한 기록(요청·응답 요약, 값 없이).
- 재시작 뒤 승인 무효·`needs_review` 동작 확인.
- 막힌 곳 목록과 각 처리(고침·이슈·보류).
