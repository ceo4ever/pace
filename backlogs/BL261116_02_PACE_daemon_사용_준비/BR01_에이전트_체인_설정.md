# BR01 에이전트 체인 설정

- 상태: 대기
- 백로그: [BL261116_02_PACE_daemon_사용_준비](BACKLOG.md)


## 목적

daemon이 요청을 실행할 에이전트 체인(default)을 만든다. 지금은 체인이 없어 요청을 받아도 실행하지 못한다.

## 범위

- `pace agent setup --agents <설계 때 정한 목록>`으로 감지(읽기만) → 계획 → 확인 → 적용. 어댑터 설치(`--install-adapters`)는 계획을 보고 결정.
- 읽기 전용 강제가 실측된 실행기만 읽기 요청에 쓰이는지 확인(`src/agent/chain.ts` `readOnlyEnforced`). Windows codex는 unelevated sandbox 수정(main f385e03b) 반영본으로.
- 제외: 체인 코드 변경.

## 완료 기준

- `pace daemon install`(계획)에서 "에이전트 체인(default)이 없다"가 사라진다.
- 체인의 각 실행기로 읽기 전용 요청 한 번씩 성공(파일 읽기 성공·쓰기 차단)한 기록이 있다.
