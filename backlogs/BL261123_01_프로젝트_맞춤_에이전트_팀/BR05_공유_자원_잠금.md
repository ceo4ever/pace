## 목적

여럿이 동시에 쓰면 깨지는 자원을 **글이 아니라 장치로** 지킨다(목표3). 근거: Studio MCP를 서브에이전트 여럿이 공유하면 충돌(DevForum 4975849·4998177, roblox-studio 브레인 `roblox-ai-개발-방식-커뮤니티-검증-2026-11`) — 지금은 정의마다 "한 번에 하나"라고 글로만 적혀 있음. 같은 종류: Studio 플레이 테스트 한 번에 worktree 하나, 브라우저 로그인 세션, 단일 기기.

## 범위

- 팀 원본 `resources: [studio-mcp]`([BR02](BR02_팀_원본_형식과_도구별_동기화.md) 형식) + 저장소 자원 목록(`.pace/team/resources.md`: 이름·동시 1·**범위**·설명). 범위는 `repo`(같은 저장소의 worktree끼리) 또는 `machine`(기기 전역 — Studio MCP·Studio 플레이 테스트처럼 머신에 하나인 자원).
- **공통 잠금 위치**: worktree마다 따로 checkout되는 `.pace/team` 아래에 두지 않는다. `repo` 범위는 모든 worktree가 함께 보는 git 공통 폴더(`git rev-parse --git-common-dir` 아래 PACE 폴더), `machine` 범위는 `PACE_HOME` 아래에 둔다.
- 잠금: `pace team lock <자원> --by <에이전트|P###>`·`unlock`·`status`. 획득마다 **소유 식별자**(획득 토큰)를 발급하고, 갱신·해제는 그 토큰이 맞을 때만 한다 — 이전 소유자의 늦은 해제·갱신이 다음 소유자의 잠금을 지우지 않는다.
- **갱신 주체**: LLM이 명령을 기억해 갱신하는 방식에 기대지 않는다. 잠금을 쥔 작업 프로세스(예: `pace team lock <자원> -- <명령>`으로 감싼 실행, 또는 작업자 프로세스의 하네스 타이머)가 갱신하고, 소유자 프로세스(PID·시작 시각)를 잠금에 기록한다.
- **회수 조건**: 갱신이 끊겼다는 것만으로 회수하지 않는다. 회수에는 두 가지가 **모두** 확인돼야 한다 — ① 소유자 프로세스(PID·시작 시각)가 끝났다 ② 실제 자원이 더 이상 쓰이지 않는다(자원 목록에 자원별 확인 방법을 둔다 — 예: Studio 플레이 모드 종료·MCP 연결 없음). 소유자가 살아 있으면 회수하지 않는다. 소유자가 끝났어도 자원이 쓰이는 중이거나, 둘 중 하나라도 확인할 수 없으면(자원 확인 방법이 없는 자원 포함) **다음 실행을 보류**하고 코디네이터에게 확인을 요청한다. 확인 방법이 없는 자원은 코디네이터·캡틴의 확인으로만 회수하고, 누가 무엇을 근거로 회수했는지 기록한다.
- 범위 명시: 잠금은 **잠금에 참여하는 호출**(코디네이터 규칙·정의에 따른 요청)만 보호한다. 참여하지 않는 직접 호출은 막지 못한다는 것을 문서와 결과에 적는다. 코디네이터 규칙(`references/coordinator.md`)에 "자원 요청 질문은 잠금으로 답한다".
- 제외: 도구 호출을 가로채 강제 차단(훅)은 실측 뒤 판단.

## 완료 기준

- 서로 다른 worktree의 두 작업자가 같은 자원을 요청하면 두 번째는 대기·거부, 갱신 중인 잠금은 만료되지 않는다(테스트).
- **갱신이 끊겼지만 소유자 프로세스가 살아 있으면 회수하지 않는다**, **소유자는 끝났지만 자원이 쓰이는 중이면 다음 호출을 보류한다**, 소유자·자원 상태 중 하나라도 알 수 없으면 보류하고 확인을 요청한다, 소유자 종료와 자원 미사용이 모두 확인된 잠금만 회수한다(테스트 — 자원 확인은 시험용 가짜 확인기로).
- 이전 소유자의 늦은 해제·갱신이 새 소유자의 잠금을 지우거나 연장하지 않는다(테스트). `machine` 범위 잠금을 다른 저장소의 작업자도 본다(테스트).
- 장치 완료는 위 시험과 PACE 쪽 임시 프로젝트의 실측(두 worktree가 시험용 자원 잠금을 공유)으로 판정한다. roblox-studio Studio MCP의 실제 직렬화 기록은 이 브리프의 완료 조건이 아니라 [BR08](BR08_첫_적용(roblox-studio_이전·새_저장소).md) 실증 표의 증거다.
