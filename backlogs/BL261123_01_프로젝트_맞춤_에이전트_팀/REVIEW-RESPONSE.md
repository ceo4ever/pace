## should_fix

| S1 | 역할 적재 대안과 실제 적용 항목 | 반영 | BR01이 호스트×경로(native·prompt)를 실측하고 실제 적용 항목(방식·모델·effort·도구 권한)을 기록. [BR03](BR03_작업자_역할_지정(start_--role).md)은 start 기록에 적용 항목을 남기고, prompt 방식은 `tier`를 모델·effort 인자로 따로 전달, 도구 권한 미적용을 기록. Codex 네이티브가 없으면 처음부터 prompt. 원본 경로 표기 정정, `--agent`(도구)·`--role`(역할) 이름 구분 |
| S2 | BR03(스킬) 선행과 현장 적용 시점 | 반영 | 스킬을 [BR07](BR07_pace-team_스킬(분석·인터뷰·설계).md)로 옮겨 BR02·BR04·BR06 뒤에 둔다(④~⑥이 미완료 명령을 기다리지 않음). 완료 기준을 "팀 설계 산출까지"로 줄이고 대표 업무 수행은 BR08로 옮겼다. roblox-studio 이전은 기존 팀을 옮기므로 스킬 없이 시작 가능 |

| S4 | BR05 작업이 살아 있는 경우의 잠금 회수 | 반영 | [BR05](BR05_공유_자원_잠금.md): 공통 위치(`repo` 범위는 git 공통 폴더, `machine` 범위는 `PACE_HOME`), 획득별 소유 토큰(늦은 해제·갱신이 새 소유자 잠금을 지우지 않음), 갱신 주체는 LLM이 아니라 작업 프로세스, 소유자 생존·자원 사용을 확인할 수 없으면 보류·확인 요청, 회수 근거 기록. 완료 기준에 해당 시험 추가 |

Studio MCP×Codex는 BR01에서 연결 가능 여부만 확인하고, 안 되면 잠금 칸은 근거와 함께 "해당 없음". 대표 결정(관문 통과 판정·외부 발송)의 승인 전 미실행, 사람의 배정·승인과 수동 보정 구분, 실측 장소를 기준선 확보 뒤로 제한 |
