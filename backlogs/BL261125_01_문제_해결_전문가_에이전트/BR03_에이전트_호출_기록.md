# BR03 에이전트 호출 기록

- 상태: 완료
- 백로그: [BL261125_01_문제_해결_전문가_에이전트](BACKLOG.md)

## 목적

팀 구성원 실행마다 에이전트·모델·effort·실행 시간·토큰을 호출 기록에 남겨 팀 모델·effort를 조정할 근거를 마련한다. BR03은 공통 저장·집계, PM 수동 입력, PACE 도구 호출을 담당한다. [백로그 목표](BACKLOG.md#목표) · [owner 원문](evidence/owner-call-log-2026-11-25.md)

## 범위

- 실제 시도 1회마다 프로젝트 또는 백로그 폴더의 `calls/log.jsonl` 1행에 다섯 항목을 직접 담는다. 모델·effort는 요청값과 실제값을 구분하고 측정 출처를 남긴다. 없는 값은 null과 미확인으로 기록한다. 실제 실패·중단·대체도 시도별 상태로 남기고 대체 사유를 기록한다. 비밀이나 프롬프트·응답 원문은 남기지 않는다. 조기 호출 반환은 별도 증거의 상대 `ref`를 연결한다.
- `pace agent run`(p·ACP와 체인), `pace agent verify`의 실제 시도는 도구가 기록한다. 명령이 실행을 거부해 시도가 없으면 호출 행이 없다. 실행 시간과 사용량은 `src/agent/contract.ts`, 체인 요청·적용 정보는 `src/agent/chain.ts`를 따른다. 실제값 출처는 관측 가능한 필드로 한정한다.
- PACE가 직접 실행한 `verify`는 검토 원장 판정의 `ref`를 남긴다. 도구 측정 시간·사용량은 원장 값과 일치하고 원장에 대응 판정이 없는 실패·중단도 별도 행을 갖는다. 검토 원장의 `미보고` 표시는 유지한다. 호출과 검토 집계는 각각의 원장을 사용한다. [BL261124_04 BR07](../BL261124_04_검토_예산과_재현_근거_지적/BR07_검토_측정과_전후_비교.md)
- PM은 `pace project log`로 같은 스키마의 호출 행을 직접 기록할 수 있다. 공통 시도 식별·결합 동작을 구현하고 [BR07](BR07_호스트_호출_기록과_외부_검토_연동.md)이 호스트 식별과 외부 검토 연결에 사용한다. 프로젝트가 없는 백로그 단계는 해당 백로그의 호출 원장을 쓴다.
- 기존 `src/project/event-log.ts`는 종류·필드를 제한하고 수치 data에 문자열과 null을 받지 않는다. 구판 일반 판독기 및 채택 팀의 엄격 판독기를 함께 검증한다. 기존 stats 시간·이벤트·토큰 구간과 팀 측정 의미를 보존한다. 신판 `pace project stats`에서 에이전트별 호출 수·시간·토큰을 별도 절로 확인한다. 채택·미채택 프로젝트 모두 호출 집계를 볼 수 있고 새 기록이 팀 채택·마감·회고를 시작시키지 않는다. [팀 측정](../../docs/TEAM-METRICS.md)
- 제외 범위는 호스트 훅·신뢰와 실제 수동 대체, 외부 검토 연결 및 필수 역할 판정(BR07), 모델·effort 자동 조정, 비용 환산, 호스트 밖 수동 세션의 사후 수집이다.

## 태스크 설계 때 확정할 항목

- 저장 형식과 구판 호환, PM 입력 형식, 프로젝트 없는 백로그 위치와 `미확인`·`미보고`의 관계를 정한다.
- S4 분량 재비교 결과 공통 장치와 호스트 연동을 분할한다. BR03에서 공통 시도 식별·결합을 만들고 BR07이 도착 순서·호스트 ID 대응과 외부 검토 인수를 담당한다. PROJECT-CLOSE에서 두 태스크를 합쳐 P-7을 판정한다.

## 완료 기준

- 자동·수동 입력은 같은 스키마를 사용한다. 다섯 항목과 출처, 미확인, 실패·중단·대체, 참조와 백로그 위치 및 거부해야 할 입력을 검사한다. 동시·중복 입력과 같은 시도의 보강은 한 행을 보존한다.
- p·ACP·체인·`verify` 정상 진입점에서 직접 기록을 확인한다. 교차 실패 후 같은 제공자 대체 성공은 이유와 상태가 있는 2행이다. 검토의 도구 측정은 원장 시간·토큰과 같고 판정 `ref`로 연결된다. 실행되지 않은 판정 예약과 검증 명령은 호출로 세지 않는다.
- 팀 채택의 역할별 호출 수·시간·토큰 및 미확인 수와 미채택의 별도 집계를 시험한다. 기존 팀 마감·회고, 검토 집계·일반 지표, 구판 팀 판독기의 호환과 통계 회귀를 확인한다.
