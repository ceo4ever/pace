# 상위 목적 (사용자 발화 원문 요약, 2026-11-14 대화 — 백로그 문서와 독립된 출처)

사용자(캡틴)가 대화에서 직접 말한 것:

1. "브라우저, API 등 에이전트가 자율적으로 자동화를 수행하게 하기 위해 쓰는 스킬이고, 사례 저장소에서 테스트를 하면서 만든 거야. 그래서 일부 사례 저장소 환경이나 구성, 구조가 보일 수 있는데 참고를 해줘."
2. "내가 원하는 것은 에이전트가 화면 + 위치 + 액션 + 추출 내용 => 이것을 이해하고 빠르게 업무를 수행하게 하는 거야. html이 사용자만 보는 용도가 아니라 에이전트가 빠르게 볼 수 있는 구조로. 예를 들어 index = 단계(html + json)로 구조화하고, html에는 화면이, json에는 내용이 있는 거지."
3. "이 스킬 때문에 이미 작업한 기존 사례 저장소에서 만들어진 스킬들에 영향이 없어야 함."
4. "만들려는 스킬은 에이전트가 자율 주행을 하는 스킬을 만드는 거야."
5. "이 스킬을 사용해서 목표 수행을 하면서, 필요시에는 사용자와 함께 하면서 그 단계를 작성해서 수행할 스킬을 최종적으로 만들어 주는 거지. 그래서 그 스킬을 실행하면 에이전트가 자율 주행을 해서 목표를 수행하겠지."
6. "(지도와 다른) 상황이 발생하면 문제를 찾아서 해결을 하게끔 작동이 되어야 하고, 해결하면 그것을 스킬에 반영해서 다음에는 그대로 작동이 되게 해줘. UI, API 변경이 발생해서 충분히 나올 수 있는 상황이야." — 안전장치(바뀐 경로의 되돌릴 수 없는 행동은 처음 한 번 확인 등)에 "좋아"로 동의.
7. "초기에는 업무 스킬을 만드는 것이 playbook을 만드는 것이잖아. 필요한 것은 인터뷰 등을 해서 수행할 업무를 파악하고, 그 다음에는 수행하면서 화면 캡처, 액션 처리 등을 진행했으면 함."
8. 스킬 이름은 `opal-playbook-maker`로 정함.
