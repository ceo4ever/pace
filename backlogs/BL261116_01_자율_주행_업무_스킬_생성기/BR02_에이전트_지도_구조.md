# BR02 에이전트 지도 구조

- 상태: 완료
- 백로그: [BL261116_01_자율_주행_업무_스킬_생성기](BACKLOG.md)

## 목적

에이전트가 단계마다 **화면 + 위치 + 액션 + 추출**을 한 번에 빠르게 파악하는 지도를 만든다(D3). 자율 주행(BR04)과 자가 복구(BR05)가 이 지도를 읽고 고친다.

## 범위

- 생성물(새 폴더, steps.json에서 켠 흐름만 — 예: `"agentView": true`):
  ```
  <흐름>/agent/
    index.json   흐름 목적·위험·시작 조건·운영 명령(run)·단계 목록[{id, 제목, 위험, 관문, html, json}]·원본 해시
    S0n.json     화면 판정(url·필수·금지 요소)·요소[{n, 이름, find, box{x,y,w,h}, action, expect, wait, onChange}]
                 ·extract[]·success·escalate·events·다음 단계
    S0n.html     단계 하나: 기준 캡처 + box 좌표의 번호 박스(독립 파일, 이미지는 shots/ 참조)
  ```
- 스키마 확장(모두 선택 필드):
  - `elements[].box` — 캡처 승인 때 코어가 기록(사람이 쓰지 않는다). 기준은 캡처 이미지 좌표, 화면 크기·배율 함께 기록.
  - `extract[]` — 그 단계에서 읽어 올 값: 필드 이름, 위치(선택자·box·API 응답 경로), 형식, 민감도(가림·저장 금지), 검증(합계·건수 대조).
  - API 단계: 엔드포인트·메서드·요청 형태(값 없이)·응답 스키마 요약·`extract` 경로. 기존 "API 단계 표기"를 필드로 정식화.
- 최신 확인: index.json·S0n.json에 steps.json 해시를 넣고, 다르면 주행 전에 멈추는 검사.
- 실값 금지 범위: steps.json의 모든 문자열(URL·query·선택자·find·문구)과 생성물(`flow.html`·`agent/*`)에 실값이 없어야 한다. 값이 들어가는 자리는 자리표시로 쓰고, 생성기는 스키마 검사에 민감 형식 탐지(주민번호·계좌·카드·전화·이메일 형식)를 넣어 걸리면 생성을 거부한다.
- 생성기·스키마 문서·테스트 갱신.
- 제외: 주행 규칙(BR04), 학습(BR05), 기존 `flow.html`·`flow/*.md` 형식 변경.

## 완료 기준

- `agentView`가 꺼진 흐름(사례 저장소 9개 포함)은 다시 생성해도 파일 목록·내용이 BR01 기준과 바이트 동일하다.
- 켠 가상 fixture 흐름에서 `agent/index.json`·`S0n.json`·`S0n.html`이 생성되고, json이 스키마 검사를 통과하며 `box`·`extract`·API 단계가 들어간다.
- 캡처 코어가 승인 캡처 때 요소 box를 기록하고, 가림 대상 요소의 box에는 원문 값을 남기지 않는다(테스트).
- steps.json을 고치고 재생성하지 않으면 해시 검사가 실패한다.
- 위치 대응: 가상 fixture 화면을 다시 띄워 각 요소의 기록된 `box`와 실제 위치를 비교했을 때 같은 요소를 가리킨다(배율·창 크기 차이 보정 포함, 테스트). 빠르기 판단의 정본은 BR06 주행 관측이고 아래 크기는 보조 지표다.
- 크기: 단계 json은 단계 하나 분량(경비 정산서 흐름을 가상 fixture로 옮긴 규모에서 단계 json 각 8KB 이하 — 목표치, 설계 때 확정).
- `npm run check` 통과.
