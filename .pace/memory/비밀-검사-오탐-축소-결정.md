사용자 결정. secret-scan의 파일 단위 제외(daemon 4개·backlogs/dashboard/data.js)를 없앴다. hasSecret은 코드 파일 확장자(.ts·.js·.mjs·.cjs·.tsx·.jsx)에서만 따옴표 없는 호출·멤버 접근·타입 표기를 오탐에서 뺀다. 마크다운·설정·redactSecrets는 엄격. data.js는 JSON을 풀어 코드 파일 경로 키의 본문만 코드 판정. 완화가 아니라 오탐 축소. 시험 test/secret-precision.test.ts.
