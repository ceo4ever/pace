작은 일(버그·문구·단발 수정)은 main에 직접 커밋한다. 프로젝트(projects/P###_…)는 worktree + project/P### 브랜치에서 진행하고 rebase 후 fast-forward로 합친다.
**왜:** 2026-10-23 작업 하네스 논의에서 루카스가 이 저장소도 프로젝트는 worktree로 하기로 승인(안 A). 설치가 복사 방식이 되어 worktree 위험이 줄었다.
**어떻게 적용:** 설치(bash scripts/install.sh)는 병합 뒤 main 체크아웃에서만 실행한다. 하네스 구현 전까지는 main 직접으로 진행한다.
