캡틴이 현재 로그아웃 곤란으로 실제 재로그온 자동 기동·콘솔 비표시 인수를 병합 후로 이관했다. T03 relogon-checklist를 따르며 원래 human-relogon-baseline은 역사 증거로 유지하고 덮어쓰지 않는다. T04·병합 뒤 인수 직전 최신 승인 운영 상태를 읽어 별도 새 post-merge 기준점을 보존한다. 같은 사용자 실제 재로그온 후 수동 start 없이 새 인스턴스·등록/런처/설정과 사람의 콘솔 비표시를 확인한 뒤만 완료한다. 미실측을 승인·현재 기동으로 대체하지 않는다.
