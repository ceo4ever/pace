## 판정과 한계 (2026-11-27)

0.1.5 team-lock과 0.1.4 S-19는 외부 환경에 기대는 시험이라는 공통점이 있으나 직접 실패 경로는 다르다. 같은 타이머·ps 조회 지연 문제로 묶을 근거는 없다. 두 원본 시험을 수정하지 않고 각각 환경을 주입해 기록된 실패와 같은 단언을 재현했다. 이는 충분조건 확인이며 당시 릴리즈 실패의 원인을 확정한 것은 아니다. 당시 호스트명 쌍·포트 오류·마법사 out 원문은 확보하지 못했다. 기존 메모리의 부하 시점 경합 추정은 확정 원인으로 쓰지 않는다.

## team-lock: 호스트 식별과 시작 조회의 순서

resource-process.ts inspectProcess는 owner.host와 현재 hostname 또는 platform이 다르면 ps/identity 호출 전에 other-host를 반환한다. 자기 갱신 시험은 실제 processIdentity를 저장한 뒤 20번의 파일 갱신을 거쳐 identity:null 주입을 검사한다. 호스트명은 주입하지 않는다. 고정 플랫폼의 같은 프로세스에서 이 분기를 관측하면 호스트명 불일치부터 조사해야 하며 ps 시간 초과 자체는 start-query-unavailable을 만든다.

hostname.mjs는 첫 hostname을 fixture-before, 이후를 fixture-after로 반환한다. 원본 시험은 101행에 실제 other-host/기대 start-query-unavailable로 실패했다. 그 전 20회 renew와 감사 수·heartbeat 단언은 통과했다. 따라서 이 실패를 갱신 중단이나 잠금 안전성 실패로 해석하지 않는다. 실제 네트워크·OS 호스트명은 바꾸지 않았다. 당시 이름이 변한 이유(네트워크 전환 등)는 미확인이다.

## S-19: 임시 폴더와 실제 TCP 자원의 격리 차이

daemon-wizard-follow의 FakeSystem·가짜 Telegram fetch는 TCP 설정 쓰기 잠금을 가짜로 만들지 않는다. withStoppedDaemon은 정규화한 home의 SHA-256을 16000개 포트로 매핑하고 실제 loopback 포트를 잡는다. 서로 다른 임시 home도 같은 포트에 매핑될 수 있고 다른 앱·검사 소켓의 점유와도 충돌한다. EADDRINUSE는 보류이며 EACCES에만 다음 후보로 간다.

port.mjs는 첫 listen(기기 설정)을 허용한 뒤 다음 listen(시크릿 저장)에서 실제 서버로 대상 포트를 먼저 점유한다. 원본 S-19가 81행 actual undefined로 실패했다. withStoppedDaemon 예외는 runDaemonInstall의 설정 실패 안내로 변환되며 자동 실행 등록은 계속되어 반환 0 단언은 통과한다. 따라서 반환 0과 시크릿 저장 성공은 다르다. 주입 소켓은 시험 프로세스 소유이며 사용자 daemon·실제 Telegram은 쓰지 않았다. 과거 실패가 포트 충돌이었는지는 원래 out/errno가 없어 미확정이다.

## 검증 범위와 비용을 줄일 수정 방향

주입 없는 대상 두 시험 baseline은 2/2, 관련 두 파일은 33/33 통과했다(skip/cancel 0, 약16.3초). 각 주입에서는 원본과 같은 단언 실패가 1건씩 발생했다. 전체 검사를 반복해 성공 표본으로 실패를 덮지 않았다. 재현 스크립트·출력은 .pace/brain/sources/release-flake-261127/에 보존했고 port 출력의 가짜 토큰 값만 치환했다.

수정 시 team-lock의 분기 단위 시험은 현재 호스트 관측을 주입해 고정하고 호스트 변화에 대한 보류는 별도 유지한다. S-19의 마법사 단위 시험은 설정 잠금 획득 경계를 주입하고 실제 포트 소유권 거부는 통합 시험으로 유지하는 방식이 적합하다. 단순 포트 사전 확인은 확인 후 점유 경합이 남고 EADDRINUSE 무조건 우회는 단일 daemon 안전 계약을 바꾼다. 실패 단언에는 마법사 out과 API 호출 단계, team-lock에는 host/platform 관측 쌍을 남겨 다음 실패를 분류할 수 있게 한다. 이 방향은 미구현이며 안정성 개선 실측으로 주장하지 않는다.
