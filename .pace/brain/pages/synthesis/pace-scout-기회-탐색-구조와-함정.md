## 왜 이렇게 나눴나

- 기계적 일(폴더·수집·렌더·검사·카드)은 `pace scout` 명령(`src/scout/`), 생각하는 일(추출·신호·후보·평가)은 스킬 `skills/pace-scout/`와 툴박스 `files/`. 명령으로 둔 이유: tsc·node:test 검사 범위 안, 설치된 어느 저장소에서나 실행, 런타임 의존성 없음.
- AI는 `report.json`만 쓰고 HTML은 템플릿이 만든다. 모든 문자열 이스케이프 + CSP `default-src 'none'`·인쇄 스크립트 해시 하나.
- 증명은 외부 증거로만: 인용·수치 원문 대조, 참조, 근거 신호, 점수 근거(+추천=1위), 추정 표시, 날짜, 링크.

## 함정

| 함정 | 증상 | 대응 |
|---|---|---|
| 유튜브 자막 timedtext | 트랙 목록은 보이는데 본문 0바이트(토큰 요구). 내부 API·토큰 흉내는 봇 차단 우회라 자동 모드도 거부 | 설명란만 자동 수집, 자막은 붙여넣기(`scout add --replace S# --method pasted`) |
| 자막 시간 `[03:41]`이 수치로 잡힘 | 영상 출처가 하나만 있어도 00~59 수치가 원문 대조를 통과 | 수치 추출 전에 시간 표기 제거 |
| 날짜를 통째로 지움 | 지어낸 날짜가 대조를 빠져나감 | 지우지 말고 앞자리 0을 뗀 수로 대조(07 = 7월) |
| 번역 요약 | October→10월, one percent→1%로 원문에 없는 숫자 생김 | `text`에도 원문에 숫자로 없던 숫자를 만들지 않는다 |
| 적합도 근거 | 루브릭은 프로필·메모리 사실을 근거로 쓰라는데 검사는 `S#`만 인정 → 근거 있는 점수가 "추정" | `프로필:`·`메모리:` 표시를 적합도에만 인정 |
| 루프 수정이 너무 넓음 | 고친 규칙이 다른 기준·다른 칸까지 열어 새 구멍(리뷰가 두 번 잡음) | 수정마다 "어디까지 허용하나"를 실패 단언으로 같이 고정 |
| worktree에서 `scout new` | main이 아니라 `$PACE_HOME/scout/`로 감 | 저장소 backlogs/에 둘 때는 `--out backlogs`(사용자가 위치를 말한 경우) |
| 정규식 본문 추출 | 사이트 메뉴·관련 기사가 섞임, JS 페이지는 댓글만 | 신호 단계에서 무시, 약한 근거로 표시 |

## 루프

결과가 틀리면 원인 레이어(프로세스·툴박스·증명)를 진단해 가장 작은 수정을 스킬 파일에 하고 재실행으로 확인한다. 피드백 고리가 생기기 전에는 프로젝트 메모리 `idea`로 기록. 첫 실행 세 번 모두 "실패한 검사 1개" — 검사가 실제로 데이터 오류와 규칙 모순을 잡았다.

## 브라우저로 유튜브 스크립트 읽기 (2026-10-29 실측)

| 브라우저 | 결과 |
|---|---|
| agent-browser가 직접 띄운 브라우저(헤드리스·`--headed`) | 실패 — `navigator.webdriver=true`, 스크립트 패널이 비어 있음 |
| 빈 임시 프로필로 띄운 일반 Chrome + agent-browser CDP 연결 | 1번 성공 뒤 재현 안 됨(원인 미확정) |
| Playwright MCP | 대체로 성공(첫날 3차, 둘째 날 1차) |
| **Orca 내장 브라우저** | 매번 성공, 2~7초 — `pace scout transcript`의 기본 경로 |

- Orca 브라우저 명령은 agent-browser와 같은 꼴(`snapshot`·`click @e3`·`eval`)이고 셸 명령이라 Claude·Codex·Cursor 어디서나 같다.
- Orca 스냅샷은 화면 밖 요소를 빼므로 버튼은 페이지 스크립트로 누른다.
- 유튜브는 첫 방문 때 `themeRefresh`로 페이지를 한 번 다시 그린다 — 버튼이 나타날 때까지 기다렸다 누른다.
- 사용자 에이전트 위장·자동화 표시 숨기기(`AutomationControlled`)·로그인 프로필은 쓰지 않는다.
- 연결되지 않은 agent-browser 세션은 `open`에서 자기 자동화 브라우저를 띄운다 — 연결 성공 전에는 open하지 않는다.
